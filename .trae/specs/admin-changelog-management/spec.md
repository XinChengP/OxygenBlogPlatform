# 后台管理日志功能规格文档

## 概述
在博客后台管理系统中增加更新日志管理功能，允许管理员在本地开发环境下对更新日志进行增删改查操作。

## 目标
- 在后台侧边栏增加"日志管理"入口
- 实现日志列表页面，支持查看所有更新日志
- 实现日志编辑/创建页面，支持新增和修改日志
- 实现日志删除功能，带确认对话框
- 与现有后台UI风格保持一致

## 非目标
- 不实现日志的富文本编辑（保持Markdown格式）
- 不修改现有的日志数据结构
- 不实现日志的版本控制

## 功能需求

### FR-1: 侧边栏导航
- 在后台侧边栏增加"日志管理"菜单项
- 包含子菜单：日志列表、撰写日志

### FR-2: 日志列表页面
- 以表格形式展示所有更新日志
- 显示字段：日期、类型、内容摘要
- 支持按类型筛选
- 支持按日期排序
- 支持分页或滚动加载
- 每行提供编辑和删除操作按钮

### FR-3: 日志编辑/创建页面
- 表单字段：
  - 日期选择器（必填）
  - 类型选择（feature/fix/refactor/docs/style/chore）
  - 内容文本域（Markdown格式）
- 支持预览功能
- 保存时验证必填字段

### FR-4: 日志删除功能
- 点击删除按钮弹出确认对话框
- 确认后执行删除操作
- 显示操作成功/失败提示

### FR-5: 数据持久化
- 使用Server Actions进行数据操作
- 修改src/content/changelogs/目录下的Markdown文件

## 技术约束
- 使用Next.js 16 App Router
- 使用TypeScript
- 使用Tailwind CSS 4
- 使用现有的Admin组件库
- 遵循现有代码规范

## 验收标准

### AC-1: 侧边栏导航
- **Given**: 管理员访问后台页面
- **When**: 查看左侧侧边栏
- **Then**: 能看到"日志管理"菜单项，包含"日志列表"和"撰写日志"子菜单

### AC-2: 日志列表页面
- **Given**: 管理员点击"日志列表"
- **When**: 页面加载完成
- **Then**: 显示所有更新日志的表格，包含日期、类型、内容摘要

### AC-3: 日志编辑功能
- **Given**: 管理员在日志列表页面
- **When**: 点击某行日志的"编辑"按钮
- **Then**: 跳转到编辑页面，表单中预填充该日志的数据

### AC-4: 日志创建功能
- **Given**: 管理员点击"撰写日志"
- **When**: 页面加载完成
- **Then**: 显示空表单，可以填写新日志信息

### AC-5: 日志删除功能
- **Given**: 管理员在日志列表页面
- **When**: 点击某行日志的"删除"按钮并确认
- **Then**: 该日志被删除，列表刷新

### AC-6: 表单验证
- **Given**: 管理员提交日志表单
- **When**: 必填字段未填写
- **Then**: 显示错误提示，阻止提交
