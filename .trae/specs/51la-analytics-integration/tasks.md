# 51la 统计接入任务列表

## 任务概述

实现 51la 网站统计的完整接入，包括全局脚本加载、文章浏览统计、小工具浏览统计等功能。

### 任务 1：创建 TypeScript 类型定义
**优先级**：高  
**依赖**：无

- [x] 创建 `src/types/analytics.d.ts` 文件
- [x] 定义 51la SDK 的全局类型声明
- [x] 扩展 Window 接口以支持 `window.LA` 对象
