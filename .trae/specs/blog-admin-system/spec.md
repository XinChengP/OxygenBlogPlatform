# 洛天依博客后台管理系统 - 产品需求文档

## 概述
- **摘要**: 为现有洛天依主题博客平台开发一个功能完善、安全可靠的**本地运行**后台管理系统，支持博文管理、动态内容管理、图床集成等核心功能。所有敏感操作在本地执行，通过 GitHub API 与远程仓库交互。
- **目的**: 简化博客内容管理流程，提供安全、便捷的管理界面，确保只有在本地环境中才能访问和修改博客内容。
- **目标用户**: 博客所有者/管理员（单一用户）。

## 目标
- 实现完整的博文管理功能（创建、编辑、发布、删除、分类、标签管理）
- 实现动态内容管理功能
- 集成远程图床仓库（Eiheir/Luo_Tianyi_Image），实现图片上传、预览、删除和链接管理
- 实现本地身份验证系统，支持密码保护
- 提供直观、响应式的用户界面
- 与现有博客平台无缝集成
- **所有敏感信息仅存储在本地，永不提交到 GitHub**

## 非目标（排除范围）
- 不实现多用户博客平台（仅支持单一管理员）
- 不实现评论审核功能（评论通过Giscus管理）
- 不实现前端页面的实时热更新（内容更新后需重新构建部署）
- 不实现复杂的工作流审批系统
- **不部署到 GitHub Pages 或任何公开服务器**

## 背景与上下文
- 现有博客平台基于 Next.js 16.1.6 构建，采用静态导出模式部署到 GitHub Pages
- 内容当前通过直接编辑 Markdown 文件并推送到 GitHub 仓库进行管理
- 已集成 GitHub API，可用于内容发布
- 图床功能需要与独立的 GitHub 仓库（Eiheir/Luo_Tianyi_Image）集成
- 项目采用 TypeScript、Tailwind CSS、React 等现代技术栈
- **后台管理系统仅在本地开发环境中运行（npm run dev）**

## 功能需求

### FR-1: 本地用户认证
- 实现本地密码设置功能（首次使用时设置）
- 实现密码登录系统
- 会话管理与超时控制（本地存储）
- 密码修改功能
- 密码重置功能（通过删除本地配置文件）

### FR-2: 博文管理
- 博文列表展示（支持分页、搜索、筛选）
- 创建新博文（Markdown 编辑器）
- 编辑现有博文
- 删除博文（含确认机制）
- 分类管理（创建、编辑、删除分类）
- 标签管理（创建、编辑、删除标签）
- 博文发布/草稿状态切换
- 置顶/取消置顶功能
- 本地文件操作 + GitHub API 提交

### FR-3: 动态内容管理
- 动态列表展示（支持分页、搜索）
- 创建新动态
- 编辑现有动态
- 删除动态（含确认机制）
- 动态置顶功能
- 图片上传与管理（支持九宫格布局）
- 本地文件操作 + GitHub API 提交

### FR-4: 图床管理
- 与 Eiheir/Luo_Tianyi_Image 仓库集成
- 图片上传（支持批量上传）
- 图片预览（支持放大、旋转）
- 图片删除
- 图片分类管理
- 图片链接生成与复制
- 图片使用统计

### FR-5: 本地配置管理
- GitHub Token 配置（本地存储）
- 图床仓库配置
- 管理员密码配置（加密存储）
- 配置导入/导出功能
- **所有配置文件添加到 .gitignore**

### FR-6: 本地操作日志
- 敏感操作本地日志记录
- 操作历史查看
- 日志清理功能

## 非功能需求

### NFR-1: 安全性
- **本地运行，不暴露到公网**
- 密码使用 bcrypt 或 Argon2 加盐哈希存储
- 输入验证与 XSS 防护
- 所有敏感配置文件添加到 .gitignore
- GitHub Token 仅在本地使用，永不提交到仓库
- 配置文件加密存储（可选）

### NFR-2: 性能
- 页面加载时间 < 2 秒
- 本地文件操作响应快速
- 支持至少 1000 篇博文的管理
- 图片上传大小限制（单张不超过 5MB）

### NFR-3: 可用性
- 直观的用户界面，操作指引清晰
- 响应式设计，支持主流现代浏览器
- 完善的错误提示和操作反馈
- 数据备份机制（配置导出）

### NFR-4: 可维护性
- 代码结构清晰，遵循项目现有规范
- 完善的代码注释
- TypeScript 类型安全
- 模块化设计，便于扩展

## 约束条件

### 技术约束
- 必须使用 Next.js 16.1.6 及现有技术栈
- 仅在本地开发环境运行（npm run dev）
- 必须与现有 GitHub 仓库集成
- 使用本地文件系统存储配置

### 业务约束
- 仅允许单一管理员用户
- 必须与现有博客内容格式兼容
- 内容更新需要触发 GitHub Actions 重新构建
- **所有敏感配置不得提交到 GitHub**

### 依赖项
- GitHub API（用于内容发布和图床管理）
- 现有 GitHub 仓库权限
- 本地 Node.js 20.9+ 环境

## 假设条件
- 管理员具备基本的 GitHub 操作知识
- GitHub Pages 部署流程保持不变
- 图床仓库 Eiheir/Luo_Tianyi_Image 可正常访问
- 管理员在可信的本地环境中使用后台系统

## 验收标准

### AC-1: 本地密码设置与登录
- **Given**: 首次使用后台系统
- **When**: 管理员设置密码
- **Then**: 密码被安全存储，后续可以登录
- **Verification**: programmatic
- **Notes**: 密码使用 bcrypt 哈希存储

### AC-2: 密码验证
- **Given**: 已设置管理员密码
- **When**: 管理员输入正确的密码
- **Then**: 成功登录并进入后台管理系统
- **Verification**: programmatic
- **Notes**: 包含登录失败的错误提示

### AC-3: 配置文件安全
- **Given**: 存在本地配置文件
- **When**: 查看 .gitignore
- **Then**: 所有敏感配置文件都在忽略列表中
- **Verification**: programmatic

### AC-4: 博文创建
- **Given**: 管理员已登录
- **When**: 管理员填写博文信息并点击发布
- **Then**: 博文保存到 src/content/blogs 目录并通过 GitHub API 提交
- **Verification**: programmatic
- **Notes**: 支持 Markdown 格式和前置元数据

### AC-5: 博文编辑
- **Given**: 存在已发布的博文
- **When**: 管理员修改博文内容并保存
- **Then**: 博文内容更新并提交到 GitHub
- **Verification**: programmatic

### AC-6: 博文删除
- **Given**: 存在已发布的博文
- **When**: 管理员点击删除并确认
- **Then**: 博文从本地和 GitHub 仓库中删除
- **Verification**: programmatic
- **Notes**: 需要二次确认

### AC-7: 分类管理
- **Given**: 管理员已登录
- **When**: 管理员创建、编辑或删除分类
- **Then**: 分类信息更新并反映在博文管理中
- **Verification**: programmatic

### AC-8: 标签管理
- **Given**: 管理员已登录
- **When**: 管理员创建、编辑或删除标签
- **Then**: 标签信息更新并反映在博文管理中
- **Verification**: programmatic

### AC-9: 动态创建
- **Given**: 管理员已登录
- **When**: 管理员填写动态内容并发布
- **Then**: 动态保存到 src/content/moments 目录并提交到 GitHub
- **Verification**: programmatic

### AC-10: 图片上传到图床
- **Given**: 管理员已登录且配置了图床仓库
- **When**: 管理员选择图片并上传
- **Then**: 图片上传到 Eiheir/Luo_Tianyi_Image 仓库并返回访问链接
- **Verification**: programmatic
- **Notes**: 支持 WebP 格式优化

### AC-11: 图片预览与管理
- **Given**: 图床仓库中有图片
- **When**: 管理员浏览图床
- **Then**: 可以预览、删除图片并复制链接
- **Verification**: human-judgment

### AC-12: 响应式界面
- **Given**: 使用不同设备访问后台（本地）
- **When**: 在桌面、平板、手机上浏览
- **Then**: 界面自适应，功能可用
- **Verification**: human-judgment

### AC-13: 输入验证
- **Given**: 管理员输入无效数据
- **When**: 提交表单
- **Then**: 显示清晰的错误提示，不接受无效输入
- **Verification**: programmatic

### AC-14: GitHub Token 安全
- **Given**: 已配置 GitHub Token
- **When**: 搜索代码库
- **Then**: Token 仅存在于本地配置文件中，未提交到 Git
- **Verification**: programmatic
