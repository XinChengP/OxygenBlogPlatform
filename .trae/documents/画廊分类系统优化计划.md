# 画廊分类系统优化计划

## 一、现状分析

### 当前分类结构
```
GALLERY_PATH_MAPPINGS 配置：
├── 表情包 (主分类)
│   └── Zi系列 (子分类)
├── 美图 (主分类)
│   ├── 横屏 (子分类)
│   └── 竖屏 (子分类)
├── 临时 (主分类)
└── 默认 (主分类)
```

### 存在的问题
1. **UI 只显示主分类** - `CategoryFilter.tsx` 中只显示一级分类，没有子分类层级
2. **类型定义不完整** - `ImageCategory` 类型缺少子分类支持
3. **分类筛选不够精确** - 无法筛选到子分类层级
4. **拓展空间不足** - 没有预留多层分类的结构

---

## 二、优化目标

### 设计原则
1. **层级清晰** - 支持主分类 + 子分类的多级结构
2. **可扩展性** - 预留更多分类拓展空间
3. **交互友好** - 分类可展开/折叠，支持精确筛选
4. **视觉美观** - 层级缩进，图标区分，与博客风格统一

---

### 展开/折叠状态管理
```typescript
// 使用 useState 管理展开状态
const [expandedCategories, setExpandedCategories] = useState<Set<string>>(new Set([
  '表情包', '美图'  // 默认展开
]));

// 切换展开状态
const toggleExpand = (categoryName: string) => {
  const newExpanded = new Set(expandedCategories);
  if (newExpanded.has(categoryName)) {
    newExpanded.delete(categoryName);
  } else {
    newExpanded.add(categoryName);
  }
  setExpandedCategories(newExpanded);
};
```
