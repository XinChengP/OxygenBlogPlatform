# 更新日志管理 (/changelog)

## 用途

当你需要：
- 记录代码层面的功能变更或技术实现调整
- 创建符合规范的更新日志文件
- 整理版本发布说明和系统架构变更
- 为变更日志页面生成新的技术条目

**不包括：** 个人动态发布、博客文章发布、内容文本编辑等纯内容类更新

## 更新日志规范

### 文件位置与命名

更新日志存储在 `src/content/changelogs/` 目录中，文件命名为 `YYYY-MM-DD.md`。

### Frontmatter 格式

```markdown
---
date: "YYYY-MM-DD"
title: "更新标题"
type: "feature|optimize|fix|docs|style|refactor"
commits:
  - "commit message 1"
  - "commit message 2"
---
```

### 类型说明

| 类型 | 说明 | 颜色 |
|------|------|------|
| feature | 新功能添加 | #66ccff (天依蓝) |
| optimize | 性能优化或代码重构 | #9966ff (紫色) |
| fix | Bug修复 | #ff66cc (粉色) |
| docs | 文档更新 | #ff9966 (橙色) |
| style | 样式调整 | #ccff66 (黄绿色) |
| refactor | 代码重构 | #66ff99 (绿色) |

### 旧类型映射（已弃用）

| 旧类型 | 映射到 | 说明 |
|--------|--------|------|
| perf | optimize | 性能优化 |
| chore | docs | 其他/杂项 |

### 内容结构模板

```markdown
## 更新概述

简要描述本次更新的核心内容和目标。

## 主要更新

### 功能/模块名称

- **具体改动点**：详细描述
- **具体改动点**：详细描述

### 另一功能/模块

- **改动点**：描述

## 技术实现

| 文件路径 | 说明 |
|---------|------|
| `src/...` | 改动说明 |

## 使用方式

### 功能名称

1. 操作步骤一
2. 操作步骤二

- 需要注意的事项二
```

## 成就标签系统

根据提交数量和日志行数自动计算成就标签：

| 成就名称 | 触发条件 | 颜色 |
|---------|---------|------|
| 略感疲惫 | 关联提交数量 >= 10 且 < 20 | #7366ff |
| 肝爆了 | 关联提交数量 >= 20 | #e566ff |
| 麻雀虽小五脏俱全 | 关联提交 = 1 且 日志行数 > 55 | #ff66a6 |

支持在日志 frontmatter 中手动配置荣誉：
```yaml
honors:
  - name: "自定义荣誉名称"
    color: "bg-gradient-to-r from-blue-500 to-purple-500"
```

## 工作流程

1. **确定日期** —— 使用今天或发布日期作为文件名
2. **确定类型** —— 根据主要变更选择最合适的类型
3. **收集提交** —— 列出相关的 commit message
4. **编写概述** —— 简明扼要地总结本次更新
5. **详述变更** —— 按模块/功能分类列出具体改动
6. **补充技术细节** —— 列出关键文件和实现说明
7. **添加使用说明** —— 如有新功能，说明如何使用
8. **标注注意事项** —— 列出兼容性、配置等注意点

## 使用示例

**你：** /changelog 记录今天的图片预览重构和社交链接扩展

**我：** 好的，我将根据项目规范创建更新日志文件...

```markdown
---
date: "2026-06-06"
title: "图片预览重构与社交链接扩展"
type: "feature"
commits:
  - "refactor: 重构图片类型与博客图片预览功能"
  - "feat: 新增抖音社交链接"
---

## 更新概述

本次更新重构了图片预览功能并扩展了社交链接渠道。

## 主要更新

### 图片预览功能重构

- **类型拆分**：将图片类型拆分为通用 `PreviewImage` 和画廊专用 `GalleryImage`
- **组件复用**：博客详情页复用画廊 `ImagePreview` 组件，支持左右切换浏览

### 社交链接扩展

- **新增抖音链接**：在关于页面添加抖音社交图标与外链

## 技术实现

| 文件路径 | 说明 |
|---------|------|
| `src/types/image.ts` | 拆分图片类型定义 |
| `src/app/about/page.tsx` | 添加抖音社交链接 |

## 注意事项

- 新增社交链接需要配置对应的环境变量
```

## 何时使用

✅ **推荐使用：**
- 完成代码功能开发后记录技术变更
- 发布版本前整理系统更新说明
- 需要按规范生成新的日志文件
- 整理一段时间内的架构或技术变更

❌ **不推荐使用：**
- 发布新的个人动态（moments）
- 发布新的博客文章（blogs）
- 仅修改了文本内容或错别字
- 临时调试代码，不会合并到主分支
- 个人本地实验性改动
