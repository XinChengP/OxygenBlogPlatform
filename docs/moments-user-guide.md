# 🎉 洛天依主题「说说」功能使用指南

## 🚀 快速开始

### 1. 访问说说功能
- 打开浏览器访问: `http://localhost:3000/moments`
- 或者通过导航栏的「说说」菜单项进入

### 2. 发布你的第一条说说

#### 2.1 基本发布
1. 点击「发布说说」按钮
2. 在文本框中输入你想分享的内容（1-200字）
3. 点击「发布」按钮

#### 2.2 添加心情标签
1. 点击「选择心情」按钮
2. 从12种心情中选择当前状态：
   - 😊 开心 - 阳光明媚的心情
   - 😢 难过 - 需要安慰的时刻
   - 🤩 兴奋 - 激动不已的状态
   - 😌 平静 - 内心宁静的感受
   - 😠 生气 - 需要发泄的情绪
   - 🥰 喜欢 - 甜蜜温馨的感觉
   - 🤔 思考 - 深度思考的时刻
   - 😴 疲惫 - 需要休息的状态
   - 🙏 感恩 - 心怀感激的心情
   - 💪 励志 - 充满动力的状态
   - ✨ 创意 - 灵感迸发的时刻
   - 😎 放松 - 悠闲自在的感受

#### 2.3 上传图片
1. 点击「添加图片」按钮
2. 选择最多9张图片（支持JPG、PNG、WEBP格式）
3. 系统会自动压缩图片，确保加载速度

### 3. 互动功能

#### 3.1 点赞
- 点击说说下方的「❤️ 点赞」按钮
- 再次点击可以取消点赞
- 点赞数会实时更新

#### 3.2 评论
- 点击「💬 评论」按钮展开评论区域
- 输入你的评论内容
- 点击「发布」按钮提交评论
- 可以给自己的评论点赞

#### 3.3 分享
- 点击「分享」按钮可以将说说分享到其他平台

### 4. 内容管理

#### 4.1 编辑说说
- 点击自己发布的说说右上角的编辑按钮
- 修改内容、心情或图片
- 点击「保存」完成编辑

#### 4.2 删除说说
- 点击自己发布的说说右上角的删除按钮
- 在确认对话框中点击「确认删除"
- 说说将被永久删除

#### 4.3 删除评论
- 只能删除自己发布的评论
- 点击评论下方的删除按钮

## 🎯 使用技巧

### 📸 图片上传技巧
1. **选择合适尺寸**: 建议上传1MB以下的图片
2. **最佳格式**: WEBP格式加载最快
3. **构图建议**: 正方形图片显示效果最佳

### 💭 内容创作建议

## 🔍 故障排除

### 常见问题

#### ❓ 无法发布说说
- **检查网络连接**: 确保网络正常
- **内容长度**: 确保内容在1-200字之间
- **频率限制**: 5秒内只能发布一次

#### ❓ 图片上传失败
- **文件格式**: 确保是JPG、PNG或WEBP格式
- **文件大小**: 单张图片不超过5MB
- **浏览器支持**: 确保浏览器支持File API

#### ❓ 页面加载缓慢
- **清理缓存**: 清理浏览器缓存
- **图片优化**: 上传更小尺寸的图片
- **网络环境**: 检查网络连接质量

## 📞 获取帮助

如果遇到其他问题，可以：

3. 尝试刷新页面或重新登录
