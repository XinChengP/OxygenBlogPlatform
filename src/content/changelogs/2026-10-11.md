## 更新概述

本次更新围绕画廊与归档两大模块展开：画廊侧新增洛天依图床工具入口，并把共享逻辑抽离为同构模块，实现浏览器端实时拉取图床数据，新文件夹无需重新构建即可识别；同时重写了路径分类匹配策略，改用最长前缀匹配修复子分类被父级规则吞掉的问题。归档页则针对超宽画布拖拽时的闪烁做了合成层优化，另有日期排序、导航标签与工具配置等细节修复。

## 主要变更

### 画廊图床工具与远程实时刷新

- **新增图床工具入口**：工具页收录洛天依图床管理工具（外部开源项目），直达仓库地址
- **共享模块抽离**：新增 `galleryShared.ts` 同构模块，将图床配置、图片判断、路径分类映射、分类树构建、GitHub Trees API 解析等逻辑集中管理，服务端与浏览器端共用同一份实现
- **浏览器端实时刷新**：页面挂载后由浏览器直接调用 GitHub Trees API 拉取最新目录树，图床新增文件夹无需重新构建部署即可被识别
- **会话级缓存**：刷新结果写入 `sessionStorage` 并设 5 分钟有效期，避免频繁切页重复请求触发 GitHub API 限流（未认证配额 60 次/小时/IP）
- **数据合并策略**：本地图片保留、远程图片整体替换为最新版本并重算分类树，可正确同步图床侧的删除与移动
- **降级保障**：拉取失败或超限时静默退出，保留构建期兜底数据，不影响正常浏览

### 画廊路径分类匹配修复

- **最长前缀匹配**：匹配时遍历全部配置并保留「匹配得最深」的一条，修复原先按顺序返回导致父级规则吞掉子级映射、子分类永不生效的问题
- **剩余部分归类**：路径比命中配置更深时，把配置未覆盖的剩余目录继续归类 —— 位于顶层兜底（`LTYpicture`）之下则剩余首段作为新主分类，位于分类容器（如 `LTYpicture/emoticon`）之下则继承主分类、剩余部分作为新子分类，实现新文件夹自动识别
- **路径规范化**：匹配前去除首尾多余斜杠，避免带尾斜杠路径导致前缀匹配与切片计算错位

### 日期排序与导航标签修复

- **日期归一化**：`formatBlogDate` 新增不补零日期（如 `2025-9-24`）的补零归一化，修复其掉入 `new Date(非标准字符串)` 后经 UTC 转换导致日期回退一天、归档时光河流串年的问题
- **索引排序修正**：搜索索引排序前先经 `formatBlogDate` 归一化，避免不补零日期按字典序排错（如 `2025-9-24` 被排到 `2025-10-01` 之后）
- **导航文案**：关于下拉菜单中「日志」改为「开发日志」，语义更清晰

### 归档页拖拽性能优化

- **常驻合成层**：为超宽画布显式添加 `willChange: 'transform'`，使其常驻 GPU 合成层，避免 framer-motion 动画结束后图层降级导致的整块画布主线程重绘
- **投影合并**：河流尽头题词的双层投影从逐字挂滤镜改为整个分组统一施加，减少滤镜区域数量，降低拖拽至最右端时的光栅化开销，解决卡片高频闪烁

### 工具与内容更新

- **新增二维码生成器**：工具页收录二维码生成器（外部开源项目）
- **描述修正**：更新 B站弹幕爬取工具的说明文案；修正文章《春岚幻月》错字；关于页歌单描述「左下」改为「左侧」
- **动漫条目**：关于页新增《魔女之旅》条目及封面

## 使用方式

### 画廊实时刷新

1. 进入画廊页面，页面挂载后自动拉取图床最新目录树
2. 图床新增文件夹后刷新页面即可看到新分类，无需重新构建部署
3. 5 分钟内的重复访问复用会话缓存，不会重复请求

### 工具页

1. 进入 `/tools` 页面
2. 在工具列表中找到「图床管理工具」或「二维码生成器」，点击后新标签页打开对应仓库

## 注意事项

- 画廊实时刷新依赖 GitHub Trees API 的未认证配额（60 次/小时/IP），同一网络下频繁强制刷新仍可能触发限流，此时页面会静默回退到构建期数据
- `galleryShared.ts` 为同构模块，**禁止**在其中引入 `fs`/`path` 等 Node 专属模块，所有路径处理一律使用字符串操作，否则浏览器端构建会失败
- 路径分类匹配已改为最长前缀匹配，新增映射规则时无需再关心配置表顺序，但子级规则的 `pathPattern` 必须是父级规则的完整前缀才能正确命中
- 归档页画布的常驻合成层会占用一定的显存，若后续画布尺寸或卡片数量大幅增长，需关注低端设备的表现
