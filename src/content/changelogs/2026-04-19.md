## 功能概述

本次更新主要对代码进行优化重构，完善静态导出模式下的类型定义，并统一页面样式。

### 代码可读性优化

#### 博客标题简化
- **标题清理**: 简化博客文章标题的显示逻辑
- **代码优化**: 提升相关组件代码的可读性和维护性

### 工具函数改进

#### 缓存机制优化
- **useThemeOptimized Hook**: 优化主题相关的性能 Hook 实现
- **工具函数增强**: 改进 `cn.ts`、`performanceUtils.ts`、`safeMarked.ts` 等工具函数
- **缓存策略**: 优化缓存机制，提升运行时性能

### 样式统一调整

#### 页面容器优化
- **内边距调整**: 移除页面容器的顶部内边距
- **样式统一**: 保持全站页面样式的一致性
- **受影响页面**:

  - 博客列表页 (`/blogs`)
  - 画廊页面 (`/gallery`)
  - 相关链接页 (`/links`)
  - 归档页面 (`/archive`)

### 静态导出模式完善

#### 类型定义增强
- **GalleryImage 接口**: 更新画廊图片接口定义
- **API 类型参数**: 为静态导出模式的 API 添加完整的类型参数
- **空数组注解**: 为静态导出模式中的空数组添加类型注解，提升类型安全

- **类型一致性**: 确保所有 API 返回值类型一致
