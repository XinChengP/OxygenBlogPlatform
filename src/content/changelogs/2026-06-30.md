## 功能概述

本次更新对项目结构进行较大规模整理：重构 `src/utils` 与 `src/lib` 工具函数路径，统一导出入口；清理冗余代码；同步调整主题配置同步脚本、变更日志图表与 UI 组件；为多个核心组件补充类型与样式细节。

## 主要变更

### 工具函数路径重构

- **入口统一**：将 `src/utils/index.ts` 重新整理为工具模块的聚合导出，所有业务侧统一通过 `@/utils` 引用
- **`utils` 与 `lib` 边界**：明确 `src/utils` 存放纯业务工具，`src/lib` 保留 shadcn 通用工具（`cn`、`clsx` 等），避免职责重叠
- **音乐播放相关工具**：`useMusicPlayer.ts`、`useLive2DLoader.ts`、`musicPlayerPreloader.ts`、`globalMusicPlayerManager.ts` 等迁移到 `@/utils` 后通过统一入口导出
- **类型集中**：`src/types/modules.d.ts`、`src/types/playMode.ts` 重新组织，补充缺失类型

### 核心组件代码整理

- **Live2D 组件**：`LuoTianyiLive2D.tsx`、`Live2DController.tsx`、`Live2DBubble.tsx`、`BrowserCompatibilityBanner.tsx`、`BilibiliIframe.tsx`、`GiscusComments.tsx` 统一引用路径，移除重复 import
- **音乐播放器组件**：`MusicPlayer.tsx` 与相关 hook 适配新的工具模块路径
- **背景样式**：`useBackgroundStyle.ts` 与 `BackgroundLayer` 工具函数重新组织
- **主题系统**：`ThemeProvider.tsx` 调整 `dynamic-title.js`、`theme-init.js` 的引用方式

### 主题与脚本优化

- **主题同步脚本**：`scripts/sync-theme-colors.js` 中优化变量提取逻辑，提高颜色转换准确性
- **主题初始化脚本**：`public/js/theme-init.js` 中清理冗余的 `try/catch`，加快首屏主题判定速度

### 变更日志页面与图表

- **`ClientChangelogsPage.tsx`**：调整时间线分组算法，按月份归类更精确
- **`TimeStatsChart.tsx` / `TypeStatsChart.tsx`**：补充图表响应式参数，修复小屏下坐标轴溢出问题

### UI 组件调整

- **`cover.tsx` / `evervault-card.tsx` / `sparkles.tsx`**：补充缺失 props 类型，移除调试日志
- **动画工具**：`animationVariants.ts` 中合并重复的 motion 预设
- **浏览器兼容工具**：`browserCompatibility.ts` 中补充 Edge 浏览器识别规则
- **性能工具**：`performanceUtils.ts` 中清理已废弃的埋点字段

### 全局配置

- **`tailwind.config.js`**：补充新增的字体、动画 keyframes 与自定义颜色 token
- **`next.config.ts` / `next-env.d.ts`**：同步类型引用与构建配置
- **`tsconfig.json`**：完善路径别名与编译选项

## 使用方式

### 验证工具函数统一引用

1. 打开 `src/utils/index.ts`，确认所有工具模块已聚合导出
2. 全局搜索 `import` 语句，验证业务侧使用 `@/utils` 而非深路径
3. 执行 `npm run lint` 确认无未使用的 import

### 查看变更日志图表

1. 访问更新日志页 `/changelogs`
2. 在窄屏与宽屏分别查看时间趋势折线图与类型分布环形图
3. 确认坐标轴与图例无溢出

## 注意事项

- 工具函数路径迁移后，旧路径下的 `import` 全部失效，请避免混用
- 主题初始化脚本清理后不再"全量重试"，若首屏主题闪烁需重新启用旧版兜底
- UI 组件 props 类型补全后，`tsc` 严格模式下可能暴露历史调用点问题，请按提示补全
- `tailwind.config.js` 新增 keyframes 需要同时在 `tailwind.config.js` 的 `animation` 中暴露
- 涉及大量 import 整理后建议执行 `npm run lint` 与 `npm run build` 双重验证
