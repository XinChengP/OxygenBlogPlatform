## 功能概述

本次更新大幅增强了后台管理系统功能，包括管理后台UI优化、本地图库管理、动态管理CRUD功能、Server Actions支持和静态导出功能。

### 主要变更

#### 管理后台UI优化
- **视觉效果增强**: 添加渐变背景和装饰元素
- **图标优化**: 使用 lucide-react 图标替换原有 SVG 图标
- **主题切换**: 改进主题切换按钮的动画效果
- **侧边栏优化**: 优化侧边栏折叠状态的交互和样式
- **导航增强**: 增强导航项的视觉反馈和动效
- **动画调整**: 调整整体过渡动画的时长和缓动函数

#### 本地图库管理
- **图库功能**: 实现本地图库管理功能
- **图片上传**: 支持图片上传到本地图库
- **图片删除**: 支持删除图库中的图片
- **列表获取**: 支持获取图库图片列表
- **文件验证**: 添加文件类型和大小验证，确保上传安全
- **目录管理**: 支持目录管理和图片分类
- **开发模式适配**: 区分静态导出和本地开发模式

#### 动态管理CRUD功能
- **完整CRUD**: 实现动态内容的增删改查功能
- **批量操作**: 支持批量操作动态内容
- **标签管理**: 支持动态标签管理
- **文件系统存储**: 使用文件系统存储动态数据
- **服务端缓存**: 支持服务端缓存更新

#### Server Actions支持
- **配置支持**: 在 next.config.ts 中添加 Server Actions 配置
- **请求体限制**: 支持 10MB 请求体限制
- **更新逻辑优化**: 重构 momentActions.ts 中的更新逻辑
- **文件上传优化**: 优化 galleryActions.ts 中的文件上传逻辑
- **文件名生成**: 根据 MIME 类型确定扩展名并添加随机字符串防止冲突

#### 静态导出支持
- **静态导出脚本**: 新增静态导出构建脚本
- **恢复脚本**: 新增恢复脚本用于恢复 Server Actions
- **静态兼容**: 将 Server Actions 替换为静态兼容版本
- **命令配置**: 更新 package.json 添加相关命令

### 技术实现

| 文件路径 | 说明 |
|---------|------|
| `src/components/admin/AdminLayout.tsx` | 管理后台布局组件 |
| `src/components/admin/AdminSidebar.tsx` | 管理后台侧边栏 |
| `src/actions/galleryActions.ts` | 图库操作 Server Actions |
| `src/actions/momentActions.ts` | 动态操作 Server Actions |
| `src/utils/editorImageUpload.ts` | 编辑器图片上传工具 |
| `scripts/prepare-static-export.js` | 静态导出准备脚本 |
| `scripts/restore-actions.js` | 恢复 Server Actions 脚本 |
| `next.config.ts` | Next.js 配置文件 |

### 使用方式

- **后台管理**: 访问 `/admin` 进入后台管理系统
- **图库管理**: 在后台管理中选择图库管理进行图片上传和管理
- **动态管理**: 在后台管理中选择动态管理进行内容的增删改查
- **静态导出**: 运行 `npm run build:pages` 进行静态导出构建

### 功能特性

- **本地开发**: 完整的后台管理功能仅在本地开发环境可用
- **静态部署**: 支持静态导出，适配 GitHub Pages 部署
- **文件安全**: 文件上传有类型和大小验证
- **缓存机制**: 服务端缓存提升性能

### 注意事项

- 后台管理功能仅在本地开发环境可用
- 静态导出后会禁用 Server Actions
- 文件上传有大小限制（默认 10MB）
- 需要 Node.js 环境运行脚本
