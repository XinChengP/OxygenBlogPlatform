## 功能概述

本次更新包含代码块组件的重构增强和暗黑模式功能的全面优化。新增代码复制功能，优化暗黑模式下的图片显示效果，提升整体用户体验。

### 主要变更

#### 代码块组件增强
- **重构 CodeBlock 组件**: 添加语言显示名称映射
- **新增复制功能**: 添加 CodeCopyButton 组件实现代码一键复制
- **样式优化**: 优化代码块样式和主题适配
- **类型定义**: 添加组件文档注释和类型定义

#### 暗黑模式增强
- **新增组件**:
  - `DarkModeFilters`: 暗黑模式滤镜包装器
  - `DarkModeImage`: 增强版图片组件
  - `useDarkMode`: 暗黑模式 Hook

- **图片优化**:
  - 支持懒加载
  - WebP 格式转换
  - 渐进式加载
  - 智能模糊占位符

- **主题切换优化**:
  - 支持系统主题同步
  - 添加过渡动画效果
  - 优化主题切换交互体验

#### 全局样式增强
- 为暗黑模式添加全局 CSS 样式
- 包括图片滤镜、内容区域优化和过渡动画

### 技术实现

| 文件路径 | 说明 |
|---------|------|
| `src/components/CodeCopyButton.tsx` | 代码复制按钮组件 |
| `src/components/tools/CodeBlock.tsx` | 增强的代码块组件 |
| `src/components/DarkModeFilters.tsx` | 暗黑模式滤镜组件 |
| `src/components/DarkModeImage.tsx` | 暗黑模式图片组件 |
| `src/components/ThemeProvider.tsx` | 主题提供者组件 |
| `src/components/ThemeToggle.tsx` | 主题切换组件 |
| `src/components/core/OptimizedImage.tsx` | 优化图片组件 |
| `src/hooks/useDarkMode.ts` | 暗黑模式 Hook |
| `src/app/globals.css` | 全局样式增强 |

### 使用方式

- 代码块自动显示复制按钮，点击即可复制代码
- 暗黑模式下图片会自动应用滤镜优化
- 主题切换支持跟随系统设置

### 注意事项

- 代码复制功能需要浏览器支持 Clipboard API
- 暗黑模式图片滤镜可能影响部分图片的色彩表现
- WebP 转换需要服务器支持
