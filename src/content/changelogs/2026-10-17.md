## 更新概述

洛天依图床从已失效的 jsDelivr 迁移到 Cloudflare Workers 静态资产，改走自有域 `img.xinchengp.cn` 提供图片；同时修复 Live2D 看板娘的点击命中区域报错与纹理加载失败问题。

## 主要变更

### 图床迁移（为何不再用 jsDelivr）

- **迁移原因**：图床仓库已达 1.5GB，远超 jsDelivr 单仓库 50MB 的服务上限，图片链接大面积失效
- **为何不用 R2**：R2 首次激活强制绑定境外银行卡，无法开通
- **最终方案**：Cloudflare Workers 静态资产——免费档即可承载（静态资产请求免费且不限量、每版本 20000 个文件、单文件上限 25MiB，当前 559 张图、最大 GIF 4.5MB，均有余量）

### Worker 侧（cloudflare/gallery-assets）

- **路由分工**：脚本只处理 `/list` 接口，图片本身由静态资产直出、不经过脚本，降低冷启动开销
- **清单接口**：`GET /list` 读取部署时生成的 `manifest.json`，返回 `{ generatedAt, count, images }`，结果缓存 2 分钟
- **自定义域**：绑定 `img.xinchengp.cn`，绕开 `*.workers.dev` 在国内的 DNS 污染问题
- **本机部署脚本**：`deploy-local.mjs` 支持「全量拉取图床 → 生成清单 → 部署」与 `--manifest-only`（图片已就位时只更新清单）
- **自动同步**：图床仓库（`Eiheir/Luo_Tianyi_Image`）的 GitHub Action 在 push `LTYpicture/**` 时执行同一流程，增量上传资产并部署
- **体积压缩**：附带 `compress-oversized.mjs`，处理超出单文件上限的图片

### 前端适配

- **回退拉取**：`galleryShared.ts` 新增 `fetchRemoteImagesWithFallback()`——优先走 `img.xinchengp.cn` 的 `/list`，失败时静默回退 GitHub Trees API（testingcf 镜像），保证图床挂掉时画廊仍可用
- **常量沿用**：`R2_IMAGE_BASE` 常量名保持不变，仅指向新域名，避免大范围改动
- **表情包布局**：表情包分类（含其子分类）图片多为方形小图，沿用美图列数会单行过大，选中时切换为更密的列数（`columns-3` ~ `xl:columns-6`）并收窄行间距，其余分类维持原布局
- **CSP 登记**：安全策略白名单补登记 `img.xinchengp.cn`

### Live2D 健壮性修复

- **命中区域判空防御**：点击命中区域数据缺失时先行判空，避免看板娘交互时报错
- **纹理加载失败自动重试**：纹理加载异常时自动重试，减少看板娘模型加载失败导致的空白

## 技术实现

| 文件路径 | 说明 |
|---------|------|
| `cloudflare/gallery-assets/wrangler.toml` | Worker 配置：静态资产目录、`/list` 拦截、自定义域 |
| `cloudflare/gallery-assets/src/index.js` | 仅处理 `/list` 清单接口 |
| `cloudflare/gallery-assets/deploy-local.mjs` | 本机部署脚本（全量 / 仅清单） |
| `cloudflare/gallery-assets/compress-oversized.mjs` | 超限图片压缩处理 |
| `src/utils/galleryShared.ts` | 图床基址改为 `img.xinchengp.cn`，新增带回退的拉取函数 |
| `src/app/gallery/GalleryClient.tsx` | 切换拉取函数、表情包分类列数适配 |
| `src/utils/cspSources.ts` | 白名单登记图床域名 |
| `public/luotianyi-live2d-master/live2d/js/live2d.js` | 命中区域判空与纹理重试 |

## 注意事项

- 清单缓存 2 分钟，图床新增图片后画廊最多延迟 2 分钟可见
- 图床自动同步依赖图床仓库配置 `CLOUDFLARE_API_TOKEN` 与 `CLOUDFLARE_ACCOUNT_ID` 两个 Secrets
- Worker 免费档限制：单文件 25MiB、每版本 20000 个文件，新增素材前需留意上限
- 原有 jsDelivr 链接已失效，历史引用需全部改走新域名
