## 更新概述

这一天主要动了两个页面：友链页从「等高三列卡片墙」改成横向名片网格，并去掉了渐变扫光、径向光晕、旋转图标块这一套模板化装饰；文章详情页新增一张底部悬浮的「阅读书签」提示，有历史阅读进度时提醒读者上次读到哪里。

友链页改版的动机是「和 /links 撞脸」——两个页面都是等高三列卡片，视觉上几乎分不清。新版把友链名片做成纸质名片的版式：左侧方形头像当证件照，右侧姓名，姓名下一条细线收口，线下面才是描述与域名；交换说明也从三张带图标的小卡退化为文档式的三栏定义列表，整页只剩天依蓝一种强调色。

## 主要变更

### 友链页改版

- **横向名片网格**：桌面三列 / 平板两列 / 手机一列，卡片内部按「头像 + 姓名 + 横线 + 描述 + 域名」纵向排布；入场节奏与 /links 对齐（单帧延迟 0.04 秒、上限 0.3 秒），悬停只保留 -3 位移、边框转天依蓝与阴影加深
- **去掉模板化装饰**：移除顶部流动渐变条、悬停径向光晕、旋转图标块、大引号与星星分隔线；卡片只用 1px 边框和一条横线区分层次
- **交换说明文档化**：原来的「我的信息 / 申请信息 / 联系方式」三张图标小卡改为 `01 / 02 / 03` 编号的三栏定义列表，头像缩成 24px 方形小图贴着名称当注脚，邮箱与留言板直接给可点链接
- **头像加载兜底**：头像域名由友站任意指定，`next/image` 的 `remotePatterns` 无法穷举，继续使用普通 `img` + `getAssetPath()`；加载失败时回退地球图标，`alt` 置空视为装饰性图片
- **访问入口**：右上角 `ArrowUpRight` 在悬停时轻微上移右移并转天依蓝，替代原来的「访问」文字按钮

### 阅读进度书签

- **书签卡版式**：底部悬浮一张书签卡，顶部垂出天依蓝缎带（底部剪出 V 形缺口），左侧进度环按弧长显示上次读到百分比，右侧是「继续」主操作与关闭按钮。相比旧版居中胶囊，位置更贴底、更窄，不再压在正文视线中心
- **显示条件**：阅读记录在 3%~92% 之间才提示；本会话已关闭过（sessionStorage 标记）不再提示；延迟 1.5 秒等首屏与水合稳定后浮出
- **自动淡出**：提示出现后读者滚走超过 140px 即视为已开始阅读，自动淡出并记住本次会话已处理，不反复打扰
- **交互细节**：进出使用弹簧动画；Esc 可关闭；跳转尊重系统「减少动态效果」设置，开启时直接跳转而不是平滑滚动

### 其他

- **归档页描述**：`时光河流 · 共 N 篇文章 · 使用 ← → 浏览` 改为 `时光河流 · 共 N 篇文章 · 更 好 的 归 档`
- **依赖升级**：`next` 与 `eslint-config-next` 升至 16.4.6
- **内容微调**：`2025-summary` 中的图片由 Markdown 语法改为标准 `img` 标签，便于控制尺寸与响应式变体

## 使用方式

### 查看续读提示

1. 阅读任意文章，滚动到 3%~92% 之间的位置后离开
2. 在同一个浏览器会话内重新打开该文章，底部会在约 1.5 秒后浮出书签卡
3. 点「继续」跳回上次位置；点关闭、按 Esc 或直接往下读一段，提示都会收起

## 注意事项

- 续读记录依赖本地阅读进度存储，清除浏览器数据或换设备后不会提示
- 关闭提示只记在 sessionStorage，换一次会话仍会提示；阅读记录本身不受影响
- 书签卡位置贴近底部，与右下角浮动按钮组在同一层级区域，调整浮动按钮位置时需一起检查遮挡
- 友链头像走普通 `img` 而非 `next/image`，这是为兼容任意域名刻意保留的取舍，不要为了「统一」改回
