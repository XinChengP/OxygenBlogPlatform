## 更新概述

这一天把学习相关的功能接进来：新增 `/study` 学习打卡页面，以 Markdown 日志形式记录每日科目、时长与笔记，配合热力图、连续天数与时间线展示；同时接入墨墨背单词开放 API，支持本地 DPAPI 加密保存 Token，每日同步学习进度、累计词汇与顽固词到前台卡片。导航结构上把「学习」从顶级导航挪进「关于」下拉菜单，保持一级导航的简洁。

## 主要变更

### 学习打卡模块

- **数据源形式**：`src/content/study-log/` 下每天一个 `YYYY-MM-DD.md` 文件，frontmatter 声明当天学习的科目（支持数组多科目，也支持单科目简写 `subject` + `minutes`）、心情（`great/good/normal/hard`）与标签，正文为当天的学习笔记。同名科目在同一天可被合并时长、笔记可被追加
- **服务器端读取**：`studyLogUtils.ts` 顶层引入 `fs/path`，仅服务端组件导入——`ClientStudyPage` 不碰任何 fs 相关的东西，避免被浏览器打包。构建期把 Markdown 正文渲染成 ReactNode 传给客户端，客户端只负责统计展示
- **统计计算**：`computeStudyStats` 输出累计打卡天数、累计学习时长、当前连续天数、历史最长连续天数、各科目累计、每天分钟数映射——后两项供热力图和 Recharts 趋势图共用
- **打卡热力图**：`HeatmapCalendar` 组件实现 GitHub 风格年视图热力图，颜色深浅按当天学习分钟数映射
- **快速打卡脚本**：`scripts/add-study-log.ts`，支持 `npm run study -- "今天学了修剪命令" -s CAD -m 60 --mood good --tags 草图` 等参数；当天已存在记录时自动合并时长、追加笔记；可 `--date` 补卡、可 `--push` 打卡后自动提交推送
- **后台管理**：新增 `studyLogActions.ts` Server Action（本地开发后台可用），后台侧边栏「学习打卡」入口，支持创建/编辑/删除打卡记录；同时纳入静态导出的空实现机制

### 墨墨背单词数据同步

- **开放 API 拉取**：调用 `https://open.maimemo.com/open/` 的 `get_study_progress`（今日已完成/计划总数、累计学习时长）与 `query_study_records`（单词学习记录，按首次学习日期聚合出历史每天新学单词数）
- **Token 三级优先级**：环境变量 `MAIMEMO_API_TOKEN` → `.maimemo-token.enc`（Windows DPAPI 加密文件）→ `.env` 明文兜底。DPAPI 密文由 `npm run maimemo -- --set-token` 交互式录入（`Read-Host -AsSecureString` 不回显），`ConvertFrom-SecureString` 绑定当前 Windows 用户，明文只在解密瞬间存在于内存
- **Worker 代理**：`cloudflare/maimemo-stats/` Worker 提供 `/api/maimemo/proxy` 中转——静态导出部署后的服务器组件无法直接访问墨墨 API，走同源 `/api/maimemo/proxy` 由 Worker 代调，同时负责签名与错误兜底
- **同步脚本**：`scripts/fetch-maimemo.ts` 本地直接拉取 + 写入 `src/data/maimemo-stats.json`，支持 `--push` 自动提交
- **前台卡片**：`MaimemoCard` 展示累计词汇、今日进度、今日新学、顽固词数量、最近学习的几个单词；未同步过或 Token 未配置时不展示卡片，页面不受影响

### 导航结构调整

- **顶级导航瘦身**：把「学习」从顶级导航的第 5 项挪出，保持顶级项数量稳定在「首页 | 博客 | 归档 | 画廊 | 动态 | 小工具」
- **关于下拉补充**：在「关于我」之前插入「学习记录」入口（`/study`），和已有的「开发日志」「相关链接」一起构成关于下拉；移动端汉堡菜单同步更新

## 使用方式

### 每日快速打卡

1. 打开终端在项目根目录
2. 执行 `npm run study -- "今天学了修剪命令" -s CAD -m 60 --mood good --tags 草图`
3. 同一天再次打卡会自动合并科目时长、追加笔记到当天文件
4. 加 `--push` 自动 git 提交并推送

### 墨墨数据同步

1. 首次录入 Token：`npm run maimemo -- --set-token`（仅 Windows）
2. 同步：`npm run maimemo`，数据写入 `src/data/maimemo-stats.json`
3. 前台页面下次构建时自动读取展示

### 后台打卡

1. 本地开发环境访问 `/admin/study`
2. 新增/编辑当天打卡记录，支持多科目与笔记

## 注意事项

- 学习打卡依赖 Node.js 24+（`fs/path` 顶层导入），`studyLogUtils.ts` 绝不能被客户端组件导入
- `MaimemoCard` 仅在服务端构建时尝试读取 JSON；未同步过（文件不存在）时返回 null，前台不渲染该卡片
- `.maimemo-token.enc` 绑定生成它的 Windows 用户，换机或换用户后需要重新 `--set-token`
- Worker `/api/maimemo/proxy` 需要在 Cloudflare Workers 部署并配置 D1 或纯函数代理；本地开发时 `next.config.ts` 的 rewrite 会转发到 wrangler dev
- `studyLogActions.ts` 纳入静态导出的空实现，`prepare-static-export.js` 已加好映射
- 导航调整只改了一项，没有影响现有的 SEO 面包屑或 sitemap；sitemap 已追加 `/study`
