## 功能概述

修复多个组件中 React Hooks 规则违反问题，确保所有 hooks 在条件返回之前调用，符合 React Hooks 规范。

### 主要变更

#### 问题修复
- **BackgroundLayer 组件**: 调整条件返回与 hooks 调用顺序
- **Footer 组件**: 确保所有 hooks 在条件判断之前调用
- **Navigation 组件**: 修复 hooks 调用顺序问题

#### 内容更新
- 添加新的动态内容 `000005.md`
- 添加对应的图片资源
- 清理 `.gitignore` 配置
- 移除待办事项中的过期内容

### 技术说明

React Hooks 规则要求：
- 所有 Hooks 必须在组件的顶层调用
- 不能在条件判断、循环或嵌套函数中调用 Hooks
- 必须确保每次渲染都以相同的顺序调用 Hooks

本次修复将所有 hooks 调用移到条件返回之前，确保符合 React Hooks 规范。
