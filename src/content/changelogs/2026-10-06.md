## 功能概述

本次更新为洛克王国阵容搭配模拟器扩充了一批宠物数据（含高魔力宠物与外观皮肤），并新增「拍照大师」血脉技能；同时对模拟器界面做了一轮细节优化，让魔力值徽章配色、右侧面板固定、通知与弹窗交互更加顺手。

## 主要变更

### 宠物数据扩充

- **新增宠物**：补充多个宠物数据，包括高魔力宠物与多种外观皮肤
- **血脉技能**：新增「拍照大师」血脉技能，丰富阵容搭配的策略维度

### 模拟器界面优化

- **魔力值徽章配色**：为不同魔力值等级配置独立的徽章文字色，亮色背景下也能保证对比度
- **右侧面板固定**：右侧面板改用纯 CSS `sticky` 固定，替代原先基于滚动监听的定位方案，减少脚本开销并避免抖动
- **通知样式优化**：调整操作通知的展示样式，提示更清晰
- **外观选择弹窗**：新增关闭按钮，方便快速关闭
- **宠物列表计数**：列表头部显示宠物数量，便于确认筛选结果

## 技术实现

| 文件路径 | 说明 |
|---------|------|
| `src/data/rocoPets.ts` | **新增**：宠物数据、外观皮肤与「拍照大师」血脉技能 |
| `src/components/tools/RocoPetSimulator/index.tsx` | 魔力值徽章配色、纯 CSS sticky 右侧面板、通知与弹窗优化 |

## 使用方式

1. 进入「阵容搭配模拟器」工具页
2. 在宠物列表中可看到新增的高魔力宠物与外观皮肤，列表顶部显示当前数量
3. 为宠物选择外观时，会弹出外观选择弹窗，可点击关闭按钮退出
4. 在血脉选择中可使用新增的「拍照大师」血脉技能

## 注意事项

- 右侧面板固定已改为纯 CSS `sticky` 实现，仅依赖样式，不再需要监听窗口滚动或尺寸变化
- 魔力值徽章配色按亮暗主题分别配置，新增魔力等级时需同步补充徽章文字色
