## 功能概述

本次更新重构了动态模块的图片预览功能，提取并统一了博客 Markdown 渲染逻辑，全面迁移 frontmatter 解析器至 gray-matter 并统一设计系统样式变量，优化了后台仪表盘统计逻辑并修复分类计数错误，清理了调试日志与未使用组件，同时更新了项目规范文档与日志模板。

## 主要更新

### 统一样式系统与 frontmatter 解析重构

- **设计系统变量统一**：替换老旧的灰度样式类为统一的设计系统变量，确保博客、画廊、更新日志、动态等页面的视觉风格一致性
- **gray-matter 迁移**：替换自定义 frontmatter 解析器为 gray-matter 库，支持复杂数组格式与标准 YAML 语法，提升解析健壮性
- **Markdown 渲染配置提取**：将复用的 Markdown 渲染配置提取为常量，避免在多处组件中重复定义相同配置
- **博客增改逻辑重构**：重构博客增改逻辑，确保更新时保留原有元数据和格式，新增 `pinned`、`pinnedAt` 字段支持文章置顶功能
- **未知字段保留**：保留原有未知 frontmatter 字段，避免在编辑过程中丢失自定义数据
- **格式缩进修复**：修复 moments 页面 frontmatter 格式的缩进不一致问题，确保 gray-matter 解析稳定

### 后台仪表盘统计优化

- **元数据提取统一**：重构文章元数据提取方式，统一使用 `parseFrontMatter`，消除仪表盘与分类页面多处解析逻辑不一致的问题
- **totalTagCount 统计**：新增 `totalTagCount` 统计字段，替换原标签数量展示，数据汇总更准确
- **分类计数修复**：修复分类计数逻辑，使用实际统计的分类数量替代预设分类，移除分类统计数量限制，完整展示全部分类
- **categoryCount 修正**：修复 `categoryCount` 统计少 1 的边界错误，确保数字与实际文章数量一致
- **动态分类统计重构**：重构 moment 页面分类标签统计逻辑，直接读取文件避免过滤条件导致的遗漏问题
- **调试日志清理**：移除 `adminUtils` 中的调试 `console` 日志，减少生产环境控制台输出噪音

### 动态图片预览重构

- **查看器统一**：移除动态模块中冗余的内嵌图片查看器实现，统一复用基于 Portal 渲染的 `ImageViewer` 组件，确保预览层挂载在 `document.body` 下，避免父元素样式干扰
- **全屏截断修复**：修复父元素 `overflow: hidden` 或固定高度导致全屏预览被截断的问题，支持客户端安全挂载与卸载
- **键盘交互增强**：新增键盘左右方向键翻页功能，用户可通过键盘快速浏览动态中的多张图片
- **点击区域翻页**：点击图片预览区域的左右侧即可触发上/下一张切换，提升大屏设备下的操作效率
- **关闭逻辑优化**：点击当前正在预览的同一张图片可直接关闭预览层，交互直觉更符合用户预期
- **组件状态同步**：`ImageGrid` 组件与 `ImageViewer` 之间的状态同步逻辑优化，确保打开/关闭/翻页状态一致

### Markdown 渲染逻辑提取与组件重构

- **组件抽离**：将 `ClientBlogDetail` 中 550+ 行的 Markdown 自定义渲染组件和工具函数提取到独立的 `BlogMarkdownComponents.tsx` 模块，主组件代码量从 580+ 行降至约 30 行，大幅降低复杂度
- **类型导出**：导出 `ReactMarkdownProps` 类型供 `LazyMarkdown` 等外部组件统一使用，提升类型复用性
- **渲染配置统一**：集中管理博客文章的 Markdown 渲染配置（代码块、图片、链接等自定义组件），避免散落在页面组件中
- **调试日志清理**：移除 `globalMusicPlayerManager` 中的调试打印日志，减少生产环境控制台输出噪音
- **类型定义统一**：统一 `LazyMarkdown`、`ClientBlogDetail` 等组件的 Markdown 渲染组件类型定义，消除类型不一致和隐式转换问题
- **未使用组件删除**：删除已废弃的 `ImageViewer` 组件（动态模块已完成查看器逻辑的内聚整合）
- **边界检查修复**：修复博客详情页的类型转换与空值边界检查，提升运行时健壮性
- **AdminTable 优化**：优化后台表格组件的单元格渲染逻辑与类型安全，减少不必要的类型断言

### 项目规范与日志模板更新

- **提交类型说明重构**：优化项目规范文档中提交类型的中文标签和旧类型映射规则表格，使类型选择更清晰
- **成就系统补充**：新增预留成就类型"人声鼎沸"的完整说明与触发条件
- **日志模板优化**：更新 changelog 技能文档中的内容结构模板和使用示例，统一更新日志编写规范
- **表述细节修正**：修正项目规范文档中的表述细节和格式规范，提升文档准确性

## 使用方式

### 动态图片预览

1. 进入动态页面，点击任意动态中的图片
2. 图片将以全屏模式打开，背景自动变暗
3. 使用键盘 `←` `→` 方向键或点击画面左右侧切换图片
4. 点击当前显示的图片可直接关闭预览
5. 按 `Esc` 键也可退出全屏预览

### 博客 Markdown 渲染组件维护

1. 博客文章的 Markdown 自定义渲染逻辑已统一迁移至 `BlogMarkdownComponents.tsx`
2. 后续如需调整代码块、图片、链接等渲染行为，直接修改该模块即可
3. 所有使用 `ReactMarkdown` 的组件可通过导入 `ReactMarkdownProps` 保持类型一致

## 注意事项

- `ImageViewer` 基于 Portal 渲染，依赖客户端环境，服务端渲染阶段不会执行挂载逻辑
- 动态图片预览的键盘事件监听在组件卸载时会自动清理，避免内存泄漏
- `BlogMarkdownComponents.tsx` 提取后，`ClientBlogDetail` 不再维护渲染细节，注意保持模块间的导入路径正确
- 删除 `ImageViewer` 组件后，若其他页面仍有引用需同步清理
- `globalMusicPlayerManager` 移除调试日志后，如遇到播放异常需借助浏览器 DevTools 手动断点调试
- gray-matter 迁移后，frontmatter 格式需符合标准 YAML 规范，避免出现缩进不一致或特殊字符导致解析失败
- 统一样式系统变量后，自定义的灰度样式类（如 `bg-gray-50` 等）需检查是否被正确替换为设计系统变量
- 仪表盘统计逻辑调整后，分类与标签的统计口径已统一为实际文件扫描结果，缓存数据需重新生成以确保显示准确
