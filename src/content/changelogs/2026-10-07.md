## 功能概述

本次更新重构了「小工具」配置与页面，移除分类筛选、改为一屏式展示，并新增外部工具支持（直接跳转 GitHub 开源仓库）；同时上架 B站弹幕爬取工具，为站内工具补充源码仓库入口，并修复了小鱼特效重复初始化导致的渲染异常。

## 主要变更

### 工具配置与页面重构

- **移除分类筛选**：删除分类侧边栏与移动端折叠菜单，页面改为全宽单列布局，特色工具与普通工具分区展示
- **新增外部工具支持**：工具项新增 `external` 与 `repoUrl` 字段，外部工具直接以新标签页打开 GitHub 仓库
- **源码入口**：站内工具卡片右上角新增仓库图标入口，底部按钮区拆分为「立即使用 + 前往仓库」并排展示
- **卡片贴底对齐**：工具卡片改用弹性纵向布局，按钮行通过 `mt-auto` 贴住卡片底边，同行卡片等高时按钮仍对齐
- **清理未激活项**：移除配置中未激活的工具项，保持列表整洁

### 新增 B站弹幕爬取工具

- **上架外部工具**：新增「B站弹幕爬取工具」，支持输入视频链接后导出弹幕，作为外部开源项目挂载
- **文案与布局适配**：调整跳转提醒文案，工具卡片布局适配不同屏幕宽度

### 小鱼特效渲染修复

- **停止旧循环**：`fish.js` 初始化时先取消可能存在的旧动画循环，保证全局只有一条渲染循环
- **清理残留画布**：重复初始化前移除容器内残留的旧画布，避免画布层层堆叠
- **解绑窗口监听**：保存 `resize` 监听器的绑定引用，重复初始化前先解绑，防止监听器无限堆积
- **页脚监听清理**：页脚组件中改用具名函数并在清理函数中解绑点击监听器，避免路由切换时监听器堆积

### 宠物模拟器配色

- **魔力值配色**：优化魔力值配色，并为组件添加局部降饱和样式，降低大面积高饱和色带来的视觉压迫

## 使用方式

### 浏览小工具页

1. 进入「小工具」页面，页面不再显示分类筛选，工具按特色与普通分区排列
2. 站内工具卡片可点击「立即使用」进入，配置了仓库的还可点击右上角图标或「前往仓库」查看源码
3. 外部工具卡片点击「前往仓库」会在新标签页打开对应 GitHub 仓库

### 使用 B站弹幕爬取工具

1. 在工具页找到「B站弹幕爬取工具」卡片
2. 点击进入对应开源项目，按其说明输入视频链接导出弹幕

## 注意事项

- 外部工具通过 `external: true` 标记，主按钮与仓库入口均指向 `path`；站内工具的源码地址使用 `repoUrl`
- 外部链接仍受全站外链守卫统一拦截提醒，未添加跳过标记
- 小鱼特效的动画循环为全局单例，任何新增初始化入口都需先释放旧循环，否则会出现速度成倍加快
