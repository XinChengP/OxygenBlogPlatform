## 更新概述

这一天做了三块改动：开发日志页的筛选栏与卡片整体改版、后台管理组件库的一轮统一重构，以及把被 Cloudflare 下线的 Qwen3 模型换成 GLM-4.7-Flash。

前两块是视觉与交互的收口——日志页新增类型短码、悬浮月份牌与时间轴联动，筛选控件从胶囊改为方形圆角；后台则补齐统一空状态、焦点陷阱与侧栏分组，把「各页面各写一版」的散装组件收敛到一处。第三块属于故障修复：原模型在 11-20 被下线（调用返回 410），问答全链路降级成 503，换模型并适配新的返回结构后恢复。

## 主要变更

### 开发日志页改版

- **筛选栏重做**：面板改为圆角更大的卡片，顶部加一条渐隐高光、右上角极淡主题色光晕；「类型 / 时间」改为固定宽度的竖排小标题，两行 chip 左边缘对齐；chip 从胶囊改为 `rounded-lg`，把「操作控件」与卡片里的胶囊标签在视觉上分层
- **选中态对比度修正**：未选中用透明边框 + 低饱和底色，悬停才浮出；选中态直接用类型色实心填充并自动选黑/白字。天依蓝亮度较高，原来压 `primary-foreground`（近白）对比度只有约 1.7:1，小字号几乎看不清，现固定深色文字
- **卡片头部重构**：新增类型短码（`feat` / `perf` / `fix` / `docs` / `style` / `refactor`）与中文标签组合徽标，日期改等宽字体；荣誉与成就标签缩小到 10px，避免头部拥挤
- **元信息重排**：折叠态的「N 次提交 / N 行正文 / N 字」改为等宽数字 + 细分隔线，形成「构建统计」的秩序感；底部操作条左右分置「展开正文」与「复制链接」
- **时间轴与悬浮月份牌**：桌面端月份标题从吸顶横条改为左侧悬浮月份牌，外层绝对定位不占文档流，卡片恢复整行宽度；牌宽 40px、左移 4px，让牌心与 24px 处的竖线对齐；卡片圆点带 `data-dot-color`，滚到牌后时直接改 DOM 点亮牌面边框、外发光与指示灯——滚动时每秒可能触发几十次，不走 `setState` 避免整页（100+ 卡片与图表）重渲染
- **移动端兜底**：手机端没有多余横向空间，退回顶部吸顶的紧凑月份标题，保留年份、月份、篇数与分隔线
- **入场动画统一**：卡片改用 Framer Motion 入场（透明度 0→1、上移 20px 归位、0.4 秒），错峰延迟单帧 0.04 秒、封顶 0.3 秒；跨月份分组用 `visibleIndexMap` 连续计数，动画节奏不会在每月初重新从 0 开始。悬停位移统一为 `y: -3`，移除原来 CSS transform 与右上角光晕，避免同一位移被两套过渡重复驱动
- **空状态与工具条**：两种空状态统一为虚线卡片 + 图标 + 操作按钮；「展开已显示 / 全部收起」改为带图标的轻量按钮组，篇数用等宽数字

### 后台管理组件重构

- **统一空状态**：新增 `AdminEmptyState`。此前表格内置一版、文章页、动态页、待办页各写一版，图标、间距、文案层级都不一致
- **焦点陷阱**：新增 `useFocusTrap`，打开时把焦点移入弹层，拦截 Tab / Shift+Tab 让焦点在内部循环，关闭时归还给触发元素。`AdminModal` 与 `AdminConfirm` 接入；确认框补充 `role="dialog"`、`aria-modal`、`aria-labelledby`、`aria-describedby`
- **确认框回车修复**：焦点停在任意按钮上时，回车交给按钮自身的点击行为——否则焦点在「取消」上按回车会同时触发取消与全局确认，一次回车产生两个相反结果；输入控件内的回车仍不接管
- **基础组件统一**：`AdminButton` 加载图标改为 lucide `Loader2`；`AdminToast`、`AdminConfirm`、`AdminSearchBar` 的内联 SVG 全部换成 lucide 图标；`AdminCard` 的 `title` 支持富文本节点，默认保持静态，只有明确可点击的卡片才开启 `interactive` 悬停抬升
- **语义变量收敛**：`AdminCard` 从 `white / gray-800` 改为 `bg-card` + `border-border`，与仪表盘图表卡、表格表面统一；`AdminLayout` 移除重复叠加的 `dark` class（根 `html` 已由 ThemeProvider 控制），首屏从居中转圈改为侧栏 + 内容骨架，避免布局跳变
- **侧栏分组**：导航按「内容 / 运营 / 系统」分组，降低十项平铺的查找成本；折叠态悬停弹出浮层补足文字并直接列出子菜单，不必先展开侧栏；去掉 `overflow-hidden`，修复折叠态徽章被裁掉的问题
- **无障碍与快捷键**：侧栏切换按钮补 `aria-expanded` / `aria-controls`，导航链接补 `aria-current`；`LazySearchDialog` 在 `/admin` 下不再接管 Ctrl+K，`AdminSearchBar` 改为全局监听并在外部 `value` 变化时同步输入框
- **仪表盘收敛**：`StatOverviewCard` 改为标签在上、数字在下，去掉纯展示卡片的悬停抬升；分类饼图改用 `AdminCard` 外壳，与旁边模块统一视觉语言

### AI 问答模型更换

- **下线故障**：原 `@cf/qwen/qwen3-30b-a3b-fp8` 于 11-20 被 Cloudflare 下线，调用返回 410 `Model has been deprecated`，问答全部降级为 503
- **替换模型**：改用 `@cf/zai-org/glm-4.7-flash`，中文口语化效果好，单次约 1.4 Neurons，免费额度可支撑 7000+ 次/天；`wrangler.toml` 与 Worker 默认值同步更新
- **关闭思考模式**：GLM 默认开启 reasoning，思考内容会吃光 `max_tokens`，导致正式回答 `content` 为 `null`（线上实测 200 token 全花在推理上）。改用 `chat_template_kwargs: { enable_thinking: false }`，单次约 2~3 秒；原 Qwen3 的 `/no_think` 模板指令对 GLM 无效，已从 user 消息末尾移除
- **兼容两种返回结构**：旧模型返回 `{ response }`，新版 OpenAI 兼容模型返回 `{ choices: [{ message: { content } }] }`。只认 `response` 会把新模型的正常回答判成空，前端显示「天依走神了」；现两种都取

## 使用方式

### 日志页筛选与月份牌

1. 打开 `/changelogs`，顶部筛选栏按类型或年份 chip 过滤，计数随另一维度联动
2. 桌面端滚动列表，左侧悬浮月份牌会随当前月份切换；卡片圆点经过牌后时，牌面亮起该日志的类型色
3. 清空筛选或切换筛选后，列表回到第一页并重新播放错峰入场动画

### 后台快捷键

1. 在任意后台页面按 Ctrl+K（macOS 为 Cmd+K），焦点会落到后台搜索框
2. 前台页面按 Ctrl+K 仍打开站内搜索弹窗，两套快捷键互不干扰

## 注意事项

- 换 AI 模型只需改 `wrangler.toml` 的 `AI_CHAT_MODEL`；若新模型不是 OpenAI 兼容返回结构，需要同步调整 Worker 的取答复逻辑
- GLM 的思考模式必须显式关闭（`enable_thinking: false`），否则正式回答会为空；不要重新加回 Qwen 的 `/no_think`
- 月份牌联动直接操作 DOM 以避开滚动重渲染，依赖「已渲染数量」与「展开状态」；新增会影响卡片高度的功能时，要把它们加入副作用依赖，否则不滚动时联动色会停在旧位置
- `AdminCard` 默认不可交互，纯展示卡片不要开启 `interactive`，否则会被误认为可点击
- 后台与前台共用 Ctrl+K：`LazySearchDialog` 必须保留 `/admin` 判断，删除后前台搜索弹窗会盖住后台
- 移除 Qwen 后记得重新部署 Worker，只改代码不 `wrangler deploy` 时线上仍是旧模型
