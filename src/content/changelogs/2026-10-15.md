## 更新概述

评论系统整体从 giscus（GitHub Discussions）迁移到 Twikoo，后端部署在 Cloudflare Workers + D1 上。迁移的直接原因：giscus 的通知由 GitHub 控制，会给所有参与过讨论的读者自动发邮件，且仓库层面无法关闭；Twikoo 只在被回复时单独通知被回复人，且本站不配置邮件通道后读者永远不会收到任何邮件。前端无需 GitHub 账号，填昵称和邮箱即可评论。

## 主要变更

### 后端（Cloudflare Workers + D1）

- **部署副本**：采用 Twikoo 官方独立 Worker 适配器（单文件纯 JS，`wrangler deploy` 即部署），完整副本入库于 `cloudflare/twikoo/`，与博客前端解耦、可独立更新
- **数据库**：D1 建于 APAC 区（东京），降低国内访客的评论读写延迟
- **自定义域名**：绑定 `twikoo.xinchengp.cn`——`*.workers.dev` 在国内存在 DNS 污染，自定义域是可达性前提
- **体积精简**：部署前自动清空 jsdom / 腾讯云内容审核 / nodemailer 三个不可用或不需要的依赖入口，包体缩小约 4.6 倍以改善冷启动
- **版本锁定**：适配器代码按 1.6 API 编写而依赖范围会解析到 1.7（已删除所用函数，导致部署失败），因此锁死 `twikoo-func@1.6.45`，升级前需确认上游已适配新 API

### 前端

- **组件重写**：`TwikooComments` 直接渲染在页面 DOM（不再是 iframe），giscus 时代的 postMessage 主题热切换与自定义样式表整体移除；因 Twikoo 的 Vue 应用会替换挂载节点，React 侧采用双层容器结构
- **脚本自托管**：`twikoo.min.js`（1.6.45）放至 `public/js/`，不依赖国内时好时坏的公共 CDN
- **主题适配**：`twikoo-theme.css` 用站点语义令牌覆盖其硬编码的 Element 调色板，亮暗模式与全站一致
- **CSP 收敛**：评论相关外部来源改为仅放行后端与表情数据源两个 connect-src 方向
- **文案与配置**：留言板与文章页说明改为「无需注册，填写昵称和邮箱即可评论」；后端地址经 `NEXT_PUBLIC_TWIKOO_ENV_ID` 构建时内联

### 数据迁移

- 历史评论经 GitHub GraphQL API 导出，markdown 正文渲染为 HTML 后映射为 Twikoo 导入格式（共 30 条）
- 路径按现行路由归一化：文章改名（`对洛佬-发癫语录` → `fadian-quotes`）的旧讨论映射到新 slug，已删除文章的测试评论剔除

## 注意事项

- 本站不配置 SMTP：读者不会收到任何邮件，博主的新评论通知走 pushoo（IM 推送）
- Workers 免费版额度：10 万请求/天、单次 CPU 10ms，个人博客量级绰绰有余
