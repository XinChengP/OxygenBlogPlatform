## 功能概述

本次更新带来三项重磅功能：Live2D 看板娘引入"上下文感知"消息系统，能够根据时间、页面、用户行为智能切换对话；关于页新增"旅行足迹地图"组件，基于 Leaflet 展示曾到访的城市；博客详情页新增"系列文章导航"，方便读者在同系列内容间跳转。同时清理了旧版实现文档并补全新方案。

## 主要变更

### Live2D 上下文智能消息系统

- **上下文追踪器（`live2dContextTracker`）**：
  - 采集时间（凌晨/早晨/下午/夜晚）、当前页面、停留时长、滚动速度、活跃状态、最近访问页面、回访次数等行为数据
  - 使用 `Set<ContextChangeHandler>` 管理订阅者，组件可注册回调以响应上下文变化
  - 抽象 `BehaviorContext` 接口统一描述用户行为环境

- **上下文消息模板（`live2dMessages`）**：
  - 在 `src/setting/live2dMessages.ts` 中按"早安/晚安/夜深/专注/离开/回访"等场景分组配置消息模板
  - 模板支持占位符（如 `{time}`、`{page}`）动态渲染

- **智能消息选择（`live2dMessageManager`）**：
  - 优化相似消息检测逻辑，避免短时间内重复推送相同类型
  - 接入上下文数据，根据 `timeOfDay`、`isLateNight`、`isInactive` 等维度匹配最合适的模板
  - 提供 `selectContextMessage(context)` 工具方法供上层调用

- **看板娘集成**：
  - `LuoTianyiLive2D` 组件中接入 `Live2DContextTracker`
  - 监听上下文变化事件，动态切换气泡消息

### 旅行足迹地图

- **基于 Leaflet 实现**：新增 `src/components/about/TravelMap.tsx`，使用 `react-leaflet` 渲染可缩放/可拖拽地图
- **分类标记**：按"已居住/已到访/想前往"等分类显示不同颜色的标记点
- **Popup 详情**：点击标记弹出城市、省份、到访日期与描述
- **自适应视口**：使用 `FitBounds` 组件自动调整地图视野以包含所有标记
- **图例展示**：地图左下角展示分类图例
- **配置驱动**：`AboutSetting.ts` 中新增 `travelLocations` 与 `travelCategoryConfig`，所有地点数据可配置
- **依赖引入**：`package.json` 中新增 `leaflet` 与 `react-leaflet` 依赖

## 使用方式

### 体验上下文智能消息

1. 打开博客首页，观察看板娘根据当前时间段（早/中/晚/夜）展示不同欢迎语
2. 持续停留在同一页面 3 分钟以上，看板娘会推送"久坐提醒"等上下文消息
3. 在多个页面之间快速切换，观察"刚刚离开又回来了"等回访类消息
4. 滚动速度明显变化时，触发"看得好认真"或"这么着急吗"类反馈

### 浏览旅行足迹地图

1. 访问关于页 `/about`，滚动到"旅行足迹"区域
2. 鼠标拖拽地图查看不同区域
3. 点击彩色标记点查看城市、日期与描述
4. 切换暗色主题，验证地图控件在深色下的可读性
5. 在 `AboutSetting.ts` 的 `travelLocations` 中新增/修改地点

### 阅读系列文章

1. 打开属于同一系列的任意博客文章
2. 在文章详情页底部查看"系列导航"，展示同系列上一篇/下一篇
3. 在 `TableOfContents` 中确认当前文章在系列内的高亮
4. 新增系列文章时，只需要在 frontmatter 中填写相同的 `series` 字段

## 注意事项

- `Live2DContextTracker` 在 `window` 不存在时不注册事件，避免 SSR 报错
- Leaflet 在 Next.js 中需要在 `useEffect` 内动态加载或显式设置 `dynamic(() => import(...), { ssr: false })`
- 系列文章导航的"上一篇/下一篇"按发布时间升序排列，置顶文章暂未特殊处理
- `live2dMessages.ts` 中模板数量较多时建议分文件维护，避免单文件过大
- 新增 `package.json` 依赖后需要执行 `npm install` 同步 `package-lock.json`
