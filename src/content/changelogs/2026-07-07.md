## 功能概述

本次更新将全局音乐播放器的底层引擎由 APlayer 替换为 Howler.js，统一了音频加载、播放控制与事件管理方式；同步重构相关 Hook、类型与样式，调整 NetEase 歌单服务、滚动管理器等周边模块；移除 APlayer 相关静态资源与 CSS 主题文件。

## 主要变更

### 底层引擎切换

- **新引擎 Howler.js**：使用 `Howl` 与 `Howler` 实例替代 APlayer，所有播放、暂停、定位、循环、静音等行为均由 Howler 直接驱动
- **移除 APlayer 资源**：删除 `public/aplayer/APlayer.min.js` 与 `APlayer.min.css`，减小静态资源体积
- **移除 aplayer-theme.css**：`src/components/aplayer-theme.css` 不再需要，已删除
- **类型重构**：`src/types/aplayer.d.ts` 重命名为 `src/types/music.ts`，新增 `HowlOptions`、`ProcessedAudioItem`、`MusicPlayerState` 等类型
- **播放模式类型**：`src/types/playMode.ts` 重新整理为与 Howler 兼容的枚举

### 核心模块改造

- **`globalMusicPlayerManager` → `howlerPlayerManager`**：
  - 在 `src/utils/howlerPlayerManager.ts` 中实现新的全局单例管理器
  - 维护播放队列、当前索引、播放历史、节流写入等状态
  - 通过 `CustomEvent` 暴露 `playmodechange`、`volumechange`、`historyupdate`、`playprogress` 等事件
  - 歌曲失败后等待 12 秒再自动跳过，避免网络抖动误判

- **`useMusicPlayer` Hook 重写**：
  - 不再依赖 APlayer 实例，全部基于 `howlerPlayerManager` 的事件进行响应式更新
  - 移除 `regenerateRandomOrder` 的多余调用参数
  - 调整随机播放算法，使用 Fisher-Yates 洗牌 + 已播放索引表，避免连续重复

- **预加载器 `musicPlayerPreloader`**：
  - 事件名同步切换为 HowlerPlayerManager 事件
  - 移除 APlayer 资源注入逻辑

- **`MusicPlayer.tsx` 重构**：
  - UI 与底层完全解耦，所有播放行为通过管理器 API 调用
  - 适配新事件名与状态字段

- **`MusicPlayerController.tsx`**：删除，统一由 `MusicPlayer.tsx` 负责

### 周边模块适配

- **网易云歌单服务**：`src/services/neteasePlaylistService.ts` 适配新接口
- **滚动管理器**：`src/utils/scrollManager.ts` 适配播放器状态变化
- **关于页配置**：`src/setting/AboutSetting.ts` 中播放器相关字段同步更新
- **Live2D 气泡**：`src/components/Live2DBubble.tsx` 适配新的事件名
- **平滑滚动**：`src/components/SmoothScrollProvider.tsx` 与新播放器事件解耦
- **历史 Hook**：`src/hooks/useMusicHistory.ts` 改为订阅 `howlerPlayerManager` 的 `historyupdate` 事件

### 全局样式

- **`globals.css`**：移除 APlayer 相关样式，补充新播放器需要的过渡与暗色适配
- **删除 `next-env.d.ts` 中的冗余类型引用**

## 使用方式

### 验证新播放器

1. 启动开发服务器，访问任意带播放器的页面
2. 播放/暂停/切歌，验证 UI 与播放状态实时同步
3. 拖拽进度条，验证 Howler 的 seek 行为正常
4. 切换播放模式（列表循环/单曲循环/随机），验证循环逻辑正确
5. 关闭网络后触发歌曲失败，验证 12 秒后自动跳过

### 适配旧事件

1. 全局搜索旧事件名（如 `aplayer:play` 等），替换为新事件名（`howler:play`）
2. 移除对 `window.aplayer` 的访问，统一通过 `howlerPlayerManager` API 调用
3. 执行 `npm run build` 确认无遗留引用

## 注意事项

- Howler 默认要求 HTTPS 或 localhost 才能正常加载音频，部署到 GitHub Pages 时已满足
- 歌曲失败自动跳过时间由 `FAILURE_AUTO_SKIP_DELAY_MS = 12000` 控制
- 进度更新节流 1 秒写入一次 localStorage，避免频繁 IO
- 单曲循环使用 Howler 原生 `loop: true`，不再通过 `ended` 事件手动重播
- 随机播放使用 Fisher-Yates 洗牌 + 已播放索引表，避免连续重复
- 旧 APlayer 主题样式已删除，若自定义站点主题中包含 APlayer 选择器，请同步清理
