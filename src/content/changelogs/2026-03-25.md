## 功能概述

本次更新包含性能优化、Bug修复和功能增强。优化了 Footer 和 ScrollToTop 组件的性能，增强了动态页面的 Markdown 渲染功能，并修复了图片处理相关问题。

### 主要变更

#### 性能优化
- **Footer 组件**: 使用 `useMemo` 和 `React.memo` 优化渲染性能
- **ScrollToTop 组件**: 使用 `useCallback` 和节流优化滚动事件处理

#### 功能增强
- **动态页面**: 增强 Markdown 渲染功能，提升内容展示效果
- **性能工具**: 添加性能优化工具函数，便于后续开发使用

#### Bug 修复
- **图片处理**: 修复当图片 src 为 Blob 类型时调用 `getAssetPath` 导致的错误
- 现在 Blob 类型图片会直接使用，避免路径处理错误

### 新增内容

- 添加新的动态内容文件
- 添加新的图片资源到 `public/Momentsabout/`

### 技术实现

| 文件路径 | 说明 |
|---------|------|
| `src/components/Footer.tsx` | 性能优化后的页脚组件 |
| `src/components/ScrollToTop.tsx` | 优化后的回到顶部组件 |
| `src/components/moments/ClientMomentsPage.tsx` | 增强的 Markdown 渲染 |
| `src/utils/performanceUtils.ts` | 性能优化工具函数 |

### 使用方式

- 性能优化已自动应用到相关组件，无需额外配置
- 动态页面现在支持更丰富的 Markdown 渲染效果

### 注意事项

- 性能优化主要针对频繁渲染的组件
- Blob 类型图片现在会自动识别并正确处理
