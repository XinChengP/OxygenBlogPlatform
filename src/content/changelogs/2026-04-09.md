## 功能概述

本次更新包含多项功能增强：GitHub手动推送功能、更新日志管理功能、Markdown frontmatter解析增强、图库管理递归扫描和目录树功能。

### 主要变更

#### GitHub手动推送功能
- **直接推送**: 支持直接推送当前更改到远程仓库
- **构建并推送**: 先执行项目构建，再推送构建产物
- **状态检测**: 自动检测 Git 仓库状态，包括分支信息、提交状态
- **防重复推送**: 智能检测是否有待推送的提交，防止重复操作

#### 更新日志管理功能
- **日志创建**: 支持创建新的更新日志文件
- **日志组织**: 自动按日期组织日志文件
- **日志展示**: 在时间线页面展示所有更新日志
- **技能文档**: 添加 changelog-manage 技能文档
- **版本更新**: 项目版本号更新至 v3.9

#### Markdown Frontmatter 解析增强
- **parseYamlValue 函数**: 新增支持内联数组和布尔值解析
- **parseFrontmatter 改进**: 兼容不同换行符格式
- **类型支持**: 增强对复杂 frontmatter 数据类型的支持

#### 图库管理增强
- **递归扫描**: 新增递归扫描所有子目录图片功能
- **目录树结构**: 添加目录树结构生成功能，用于UI导航
- **子目录导航**: 实现子目录快速导航接口，包含图片数量统计
- **排除目录配置**: 增加排除目录配置，避免扫描特定目录
- **性能优化**: 优化图片获取性能，添加缓存和错误处理

### 技术实现

| 文件路径 | 说明 |
|---------|------|
| `src/hooks/useGitHubPush.ts` | GitHub推送Hook |
| `src/actions/githubActions.ts` | Git操作Server Actions |
| `src/actions/galleryActions.ts` | 图库操作Server Actions |
| `src/hooks/useGallery.ts` | 图库管理Hook |
| `src/actions/blogActions.ts` | 博客操作（含frontmatter解析） |
| `.trae/skills/changelog-manage/SKILL.md` | 更新日志管理技能文档 |

### 使用方式

- **GitHub推送**: 在后台管理界面点击"推送到GitHub"按钮
- **更新日志管理**: 使用技能工具创建和管理更新日志
- **图库递归扫描**: 在图库管理中自动递归扫描子目录
- **目录树导航**: 通过目录树快速导航到不同分类

### 功能特性

- **GitHub推送**: 实时状态反馈，防重复推送机制
- **日志管理**: 完整的创建、组织、展示流程
- **Frontmatter解析**: 支持数组、布尔值等复杂类型
- **图库管理**: 递归扫描，目录树导航，性能优化

### 注意事项

- GitHub推送功能仅在本地开发环境可用
- 图库递归扫描可能需要一定时间，已添加缓存优化
- 更新日志需要按照规范格式编写
