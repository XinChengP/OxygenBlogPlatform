## 功能概述

新增 GitHub 手动推送功能，支持在后台管理界面直接推送代码到 GitHub 仓库，无需使用命令行操作。

### 主要变更

#### GitHub推送功能
- **直接推送**: 支持直接推送当前更改到远程仓库
- **构建并推送**: 先执行项目构建，再推送构建产物
- **状态检测**: 自动检测 Git 仓库状态，包括分支信息、提交状态
- **防重复推送**: 智能检测是否有待推送的提交，防止重复操作

#### 技术实现
- 新增 `useGitHubPush` Hook 管理推送状态
- 新增 `githubActions` Server Actions 处理 Git 操作
- 支持推送状态实时反馈（推送中、构建中、完成、错误）
- 支持自定义提交信息

### 技术实现

| 文件路径 | 说明 |
|---------|------|
| `src/hooks/useGitHubPush.ts` | GitHub推送Hook |
| `src/actions/githubActions.ts` | Git操作Server Actions |

### 使用方式

1. 进入后台管理界面
2. 在需要推送的页面点击"推送到GitHub"按钮
3. 选择直接推送或构建并推送
4. 查看推送结果和状态反馈

### 功能特性

- **状态管理**: 实时显示推送和构建状态
- **错误处理**: 详细的错误信息和处理建议
- **状态刷新**: 自动刷新 Git 状态，保持信息同步
- **安全控制**: 防止重复推送，避免冲突

### 注意事项

- 仅在本地开发环境可用
- 需要配置 Git 用户信息
- 推送前请确保代码已提交
- 构建推送会执行 `npm run build` 命令
