## 变更概述

调整开发服务器端口配置，并对音乐播放器和页面样式进行优化。

## 主要变更

### 端口配置调整

- **开发服务器端口**：从 `3000` 调整为 `7120`
- **配置文件更新**：
  - `package.json`: `next dev -p 7120`
  - `start-dev.bat`: 更新端口检查逻辑
  - `electron/main.js`: 更新所有 URL 配置

### 音乐播放器优化

- **样式优化**：调整播放器外观，提升视觉效果
- **交互体验**：优化播放控制按钮的交互反馈
- **响应式适配**：改进移动端显示效果

### 页面样式优化

- **布局调整**：优化页面整体布局结构
- **视觉一致性**：统一各页面的设计风格
- **细节打磨**：修复边缘视觉问题

## 文件变更

| 文件路径 | 说明 |
|---------|------|
| `package.json` | 更新 dev 脚本端口参数 |
| `start-dev.bat` | 更新端口检查和提示信息 |
| `electron/main.js` | 更新所有 URL 的端口配置 |
| `src/components/widgets/MusicPlayer.tsx` | 样式和交互优化 |

## 端口变更原因

将开发端口从默认的 `3000` 调整为 `7120`，避免与其他本地服务冲突，提高开发环境的兼容性。

## 使用方式

启动开发服务器：
```bash
npm run dev
# 或
start-dev.bat
```

开发服务器将在 `http://localhost:7120` 启动。
