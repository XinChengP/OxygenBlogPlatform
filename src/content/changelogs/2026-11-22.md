## 更新概述

这一天主要做了三件事：补齐 SEO 收录体系（canonical、准确 lastmod、IndexNow 主动推送、关闭 Cloudflare 托管的错误 robots.txt），把完整后台重新纳入版本控制并确保它不进入线上产物，以及统一全站动效参数、补齐移动端博客分类筛选。

SEO 部分解决的都是「提交了但收录慢、收录了但描述不对」的具体问题：此前基础页面的 `lastModified` 全部写 `new Date()`，每次构建都发出假的新鲜度信号；文章 `excerpt` 普遍只有 6~20 字，Bing 直接提示描述过短；Cloudflare 的托管 robots.txt 在源站规则前追加了对 Baiduspider、Bytespider、PetalBot 的全站 Disallow，百度、字节、华为爬虫实际上一直被挡在门外。

## 主要变更

### SEO 与收录

- **canonical 全覆盖**：about / archive / blogs / changelogs / friends / gallery / guestbook / links / moments / redirect / settings / study / subscribe 等页面统一补 canonical，避免带查询串或重复路径被当成多份内容
- **sitemap 使用真实 lastmod**：新增 `getLatestContentDate()`，取博客（优先 `updatedAt`）、动态、更新日志三类内容的最新日期，作为基础页面的最后更新时间；站点没有内容时才回退到当前时间
- **文章描述自动生成**：新增 `buildSeoDescription()`，从正文提取纯文本生成约 60~140 字描述（剔除代码块、HTML 实体、图片与链接语法），解决多数 `excerpt` 过短的问题；优先级为 `seoDescription` > `excerpt` > 正文自动提取
- **标题修正**：`seoTitle` 此前完全不生效，现优先读取；标题格式从「文章标题 - OxygenBlogPlatform | 心想事成的个人博客」改为「文章标题 | 心想事成的个人博客」，避免一段标题里出现两个站点名
- **IndexNow 主动推送**：新增 `submit-indexnow.mjs` 与部署步骤。push 触发时用 `git diff` 生成变更清单，只推受影响的页面；定时/手动触发没有可比对提交，回退为全量推送。删除的页面不会误推
- **关闭托管 robots.txt**：新增手动工作流，通过 Cloudflare API 把 `is_robots_txt_managed` 置为 false，并主动清理 robots.txt 缓存、打印线上前 40 行核对。托管规则会在源站文件前追加 `Disallow: /`，是百度等爬虫无法抓取的直接原因

### 完整后台释放

- **源码入库**：`src/app/admin` 重新纳入版本控制，博客、动态、日志、图床、学习、待办、设置、备份等管理页完整恢复，后台不再依赖本地未跟踪文件
- **产物排除**：构建前不再移动源目录（Windows 下 IDE 索引会持有目录句柄，`renameSync` 随机抛 `EPERM` 导致构建中断）；改为构建成功后由 `build-pages.js` 的 `cleanAdminArtifacts()` 删除 `out/admin` 与 `out/_next/static/chunks/app/admin`
- **失败即报错**：清理失败会返回非零退出码，避免后台页面被静默部署到线上

### 动效与页面细节

- **动效常量统一**：新增 `src/utils/motion.ts`，统一入场位移 14px、时长 0.35s、逐项延迟 60ms 与缓动曲线；此前首页 Hero 75px、PageHeader -20px、工具卡片每张额外延迟 0.1s，页面之间手感不一致
- **页脚与字体**：页脚增加可读性遮罩，解决亮色模式下白字压在浅色背景上看不清；标题统一 `font-heading`，阴影统一走 `shadow-card` 令牌
- **移动端博客分类**：新增横向滚动 chip 筛选条，与桌面侧栏共用 `selectedCategory` 状态；此前小屏完全没有分类入口
- **文章卡片减负**：移除悬停遮罩、浮层按钮与多层 motion 动画，封面缩放改由 CSS `group-hover` 驱动，单张卡片的动画实例从 6 个以上降到 1 个
- **归档封面响应式**：改用 `ManifestImage` 并指定 `sizes`，时光河流一屏不再请求十几张 4000px 原图
- **中文文件名修复**：`getResponsiveImageEntry` 增加查询串剥离与 `decodeURI` 兜底，修复 react-markdown 百分号编码后中文图片查不到变体、始终加载原图的问题

## 使用方式

### 使用完整后台

1. 本地启动 `npm run dev`，访问 `/admin` 即可进入完整管理后台
2. 后台页面只用于本地开发；`npm run build:pages` 会在构建后自动从 `out` 中删除 `/admin` 产物
3. 若清理失败，构建会以非零码退出，需要检查 `out/admin` 是否被其他程序占用

### 核对爬虫收录

1. 在 Actions 页面手动运行「关闭 Cloudflare 托管 robots.txt」，确认输出「百度爬虫不再被全站禁止」
2. 推送后查看 IndexNow 步骤日志，确认本次推送的是增量页面而非全站
3. 定时/手动触发部署时没有 `git diff` 可比对，脚本会按全量推送

## 注意事项

- 后台源码入库后，`src/app/admin` 不能再加入 `.gitignore`；线上安全依赖构建后清理，而不是源码不入库
- 不要在构建前移动 `src/app/admin`，Windows 下会因 IDE 目录句柄触发 `EPERM`
- IndexNow 增量模式要求变更文件能正确映射到页面；新增内容目录或改路由规则时，需同步 `resolveChangedUrls`
- Cloudflare 托管 robots.txt 关闭后仍可能被 WAF 或安全规则拦截爬虫，工作流末尾的核对步骤只验证 robots 规则本身
- 文章描述自动提取只做「够用就好」的清洗，若正文以图片为主，建议仍然手写 `seoDescription`
