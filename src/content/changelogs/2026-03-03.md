## 功能概述

新增待办事项管理功能，支持在动态页面侧边栏展示待办列表，并在后台管理界面进行增删改查操作。

### 主要变更

#### 前台展示
- 在动态页面（/moments）侧边栏新增待办事件小组件
- 支持展示待办内容、完成状态、优先级、截止日期
- 显示完成进度统计（总数/已完成数/完成率）
- 按完成状态和优先级自动排序
- 完全兼容 GitHub Pages 静态部署

#### 后台管理
- 新增待办管理页面（/admin/todo）
- 支持添加、编辑、删除待办事项
- 支持标记完成/取消完成状态
- 支持按状态（全部/未完成/已完成）筛选
- 支持按优先级（高/中/低）筛选
- 支持关键词搜索
- 支持批量删除操作
- 在侧边栏添加"待办管理"导航入口

#### 数据结构
- 待办数据存储于 `src/content/todo.json`
- 支持优先级设置（high/medium/low）
- 支持截止日期设置
- 记录创建时间和更新时间

### 技术实现

#### 新增文件
| 文件路径 | 说明 |
|---------|------|
| `src/types/todo.ts` | 待办类型定义 |
| `src/content/todo.json` | 待办数据存储 |
| `src/actions/todoActions.ts` | Server Actions |
| `src/components/moments/TodoWidget.tsx` | 前台展示组件 |
| `src/app/admin/todo/page.tsx` | 后台管理入口 |
| `src/app/admin/todo/TodoManageClient.tsx` | 后台管理客户端组件 |

#### 修改文件
| 文件路径 | 说明 |
|---------|------|
| `src/app/moments/page.tsx` | 添加待办数据读取 |
| `src/components/moments/ClientMomentsPage.tsx` | 集成待办组件 |
| `src/components/admin/AdminSidebar.tsx` | 添加导航入口 |

### 使用方式

1. **前台展示**：访问 `/moments` 页面，在右侧侧边栏查看待办列表
2. **后台管理**：本地开发环境访问 `/admin/todo` 管理待办事项
3. **部署更新**：修改待办后运行 `npm run build:pages` 重新构建部署
