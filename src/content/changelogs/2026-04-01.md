## 功能概述

为博客文章和动态添加隐藏属性，支持在前台构建时过滤隐藏内容。后台管理系统支持切换单个和批量内容的隐藏状态，确保 GitHub Pages 静态部署时不会显示隐藏内容。

### 主要变更

#### 隐藏属性支持
- 为博客文章添加 `hidden` 属性
- 为动态内容添加 `hidden` 属性
- 支持在前台构建时自动过滤隐藏内容

#### 后台管理增强
- 支持单个内容的隐藏状态切换
- 支持批量内容的隐藏状态管理
- 在后台管理界面显示隐藏状态标识

#### 静态部署兼容
- 确保 GitHub Pages 静态部署时不会显示隐藏内容
- 隐藏内容仅在后台管理系统中可见

### 技术实现

| 文件路径 | 说明 |
|---------|------|
| `src/actions/blogActions.ts` | 博客文章操作增强 |
| `src/actions/momentActions.ts` | 动态内容操作增强 |
| `src/app/blogs/page.tsx` | 博客页面过滤逻辑 |
| `src/hooks/useAdminBlogs.ts` | 后台博客管理 Hook |
| `src/utils/momentsUtils.ts` | 动态工具函数增强 |

### 使用方式

- 在后台管理系统中，可以设置博客文章或动态的隐藏状态
- 隐藏的内容不会在前台页面显示
- 支持批量操作，提高管理效率

### 注意事项

- 隐藏状态修改后需要重新构建部署才能生效
- 隐藏的内容仍然保留在仓库中，只是不在前台展示
