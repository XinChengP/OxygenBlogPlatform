## 功能概述

为洛克王国宠物模拟器添加多账号管理、批量操作、图标缓存等功能，提升用户体验和操作效率。

## 主要变更

### 多账号管理系统

- **账号切换**：支持创建、切换多个玩家账号
- **宠物收藏**：每个账号独立记录已拥有的宠物
- **预设账号**：内置"心想事成awa"账号，包含118只宠物数据
- **双存储机制**：账号数据使用 Cookie + localStorage 持久化

### 批量操作功能

- **批量选择**：支持多选宠物进行批量操作
- **批量禁赛**：一键将选中的宠物加入禁赛列表
- **批量阵容**：一键将选中的宠物加入出战阵容
- **拖拽面板**：批量操作栏支持拖拽移动，避免遮挡内容

### 导入导出功能

- **数据导出**：将当前账号的宠物数据导出为ID或名称列表
- **数据导入**：从文本导入宠物数据到当前账号
- **格式切换**：支持按宠物ID或宠物名称格式导入导出

### 宠物图标缓存

- **内存缓存**：使用 Map 存储已加载的图片 URL
- **localStorage 记录**：持久化记录已成功加载的图片地址
- **预加载机制**：页面加载完成后自动预加载可见宠物图标
- **性能优化**：避免每次刷新页面都重复从网络请求图片

### UI 优化

- **拥有标识**：已拥有的宠物显示绿色边框
- **筛选功能**：支持"仅显示已拥有"筛选模式
- **操作栏改进**：批量操作栏移至左上角，支持拖拽定位

## 技术实现

| 文件路径 | 说明 |
|---------|------|
| `src/components/tools/RocoPetSimulator/index.tsx` | 模拟器主组件，添加账号管理和批量操作逻辑 |
| `src/data/rocoPets.ts` | 宠物数据，添加账号管理和预设账号数据 |
| `electron/main.js` | Electron主进程，添加全局快捷键、托盘、菜单、IPC处理 |
| `electron/preload.js` | Electron预加载脚本，暴露API给渲染进程 |

## 使用方式

1. **账号管理**
   - 点击账号下拉框切换不同账号
   - 点击"+"按钮创建新账号
   - 选择"显示已拥有"筛选当前账号的宠物

2. **批量操作**
   - 点击"批量"按钮进入批量选择模式
   - 点击宠物左上角的复选框选择宠物
   - 拖拽批量操作栏到合适位置
   - 点击"禁赛"或"阵容"按钮执行批量操作

3. **导入导出**
   - 点击"导入/导出"按钮打开对话框
   - 选择导出格式（ID或名称）
   - 粘贴宠物数据文本进行导入

## Electron 开发预览工具功能增强

全面增强 Electron 桌面应用的开发预览功能，添加大量实用工具和快捷键支持。

### 新增功能

#### 常用页面快速跳转
- **快捷键支持**: Alt+1~8 快速跳转到各个页面
- **支持页面**: 博客列表、归档、画廊、动态、更新日志、留言板、工具页面、404页面
- **前后台切换**: Alt+Home 返回首页，Alt+End 进入后台

#### 窗口管理功能
- **全局快捷键 F11**: 切换全屏模式（修复了之前无法触发的问题）
- **全局快捷键 Esc**: 退出全屏模式
- **重置窗口**: Ctrl+Shift+0 重置为默认尺寸 (1400x900)
- **最小化到托盘**: Ctrl+M 或点击关闭按钮
- **多窗口支持**: Ctrl+Shift+T 打开新窗口，Ctrl+Shift+D 复制当前窗口
- **托盘图标**: 支持显示/隐藏窗口，右键菜单操作

#### 开发辅助工具
- **页面截图**: Ctrl+Shift+S 截取当前页面并保存到图片文件夹
- **性能监控**: Ctrl+Shift+P 显示内存使用、页面加载时间等性能指标
- **控制台日志**: Ctrl+Shift+C 打开独立的控制台日志窗口
- **清除缓存**: Ctrl+Shift+Delete 清除浏览器缓存和存储数据

#### 视图控制
- **缩放控制**: Ctrl++ 放大，Ctrl+- 缩小，Ctrl+0 重置
- **主题切换**: 菜单栏支持强制切换深色/浅色模式
- **开发者工具**: F12 切换开发者工具
- **窗口置顶**: 菜单栏可设置窗口始终置顶

#### 快捷操作
- **复制URL**: Ctrl+Shift+U 复制当前页面地址
- **浏览器打开**: Ctrl+Shift+O 在系统默认浏览器中打开当前页面
- **项目文件夹**: Ctrl+Shift+F 打开项目根目录
- **配置文件**: 菜单栏快速打开 package.json、next.config.ts 等配置文件
- **内容文件夹**: 菜单栏快速打开博客、动态、日志等内容目录

#### 构建与更新
- **运行构建**: Ctrl+Shift+B 执行 npm run build
- **重启服务器**: Ctrl+Shift+N 重启 Next.js 开发服务器
- **检查更新**: 菜单栏查看当前版本信息

## 注意事项

- 账号数据保存在浏览器本地，清除缓存会丢失
- 预设账号"心想事成awa"包含的宠物数据
- 图标缓存首次加载后生效，后续刷新将从缓存读取
- 批量操作栏支持拖拽，可移动到页面任意位置
- Electron 全局快捷键在应用退出时会自动注销
- 托盘功能需要 favicon.ico 图标文件存在
