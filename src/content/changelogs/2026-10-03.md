## 更新概述

本次更新围绕「减负与统一」展开：把散落在各处的工具函数与博客渲染链路收敛为单一实现，将相关链接页重构为带搜索与分类导航的可视化资源页，并彻底移除 jQuery 依赖、改为按需注册 Prism 语言包，在保留全部功能的前提下明显缩小打包体积、提升首屏加载速度。

## 主要更新

### 相关链接页重构

- **品牌图标体系**：新增品牌图标模块，内联 simple-icons 官方 SVG 轮廓（Next.js、Tailwind CSS、TypeScript、Framer、shadcn/ui、Lucide、GitHub、bilibili、Markdown、date-fns 等），不依赖运行时请求，统一使用 `currentColor` 着色以跟随分类色
- **图标解析优先级**：按「`icon` 字段品牌图标 → `icon` 字段语义 Lucide 图标 → URL 特征（github/bilibili）→ 分类图标 → 通用地球图标」逐级兜底，保证任何链接都有合适图标
- **搜索过滤**：顶部粘性工具栏新增搜索框，按名称、描述、标签、分类名实时过滤，空分组自动隐藏，统计计数同步更新
- **分类快速导航**：分类胶囊横向滚动（移动端友好），点击平滑滚动到对应分组，禁用态显示为无结果分类
- **Scrollspy 高亮**：滚动时自动高亮当前所在分类，点击导航后加短暂「时锁」避免滚动途中高亮被抢走
- **卡片视觉统一**：链接卡片改用原生 `<a>` 标签（支持键盘 Tab 聚焦、回车打开、中键新开标签页），视觉对齐全站卡片令牌，底部新增域名信息栏

### 工具函数统一

- **剪贴板统一**：新增全站唯一的 `copyToClipboard`，优先使用 Clipboard API 并提供 `execCommand` 降级方案；替换后台工具、代码复制按钮、分享面板、博客密码复制、关于页、拼音转换器、洛克王国模拟器、Markdown 编辑器等多处重复实现
- **相对时间统一**：新增全站唯一的 `formatRelativeTime`，统一了留言板与 GitHub 留言板此前两份行为略有差异的实现（时间数字与单位无空格、包含「昨天」分支，超过一周回退为本地化日期）

### 博客渲染流程重构

- **纯展示映射**：新增不标注 `use client` 的纯组件映射模块，服务端渲染器与客户端可共用同一份 Markdown 组件映射
- **服务端渲染入口**：新增服务端渲染组件，交互类元素（代码块、图片、iframe）单独映射到对应客户端组件
- **主题自适应代码块**：由客户端组件在水合时通过 `next-themes` 决定高亮配色，服务端与水合前统一使用亮色主题
- **上下文与富媒体拆分**：新增文章上下文、图片、iframe 组件；删除旧的懒加载 Markdown、组件映射与详情包装模块

### 移除 jQuery 依赖

- **删除 jQuery**：移除 `public/js/jquery.min.js`，页脚、鱼群脚本、平滑滚动、滚动管理与音频播放管理等模块全部去 jQuery 化
- **Prism 按需注册**：新增按需注册的高亮器，仅注册常用语言（含博客中出现的 bash/html 等场景），替代会把数百种语言打入 chunk 的全量入口
- **语言归一化对齐**：注册名与博客渲染的语言归一化结果保持一致（如 `sh/shell/zsh → bash`、`py → python`、`cxx/c++ → cpp`、`yml → yaml`）

## 使用方式

### 浏览相关链接页

1. 进入「相关链接」页面，顶部为粘性工具栏（搜索框 + 分类胶囊）
2. 在搜索框输入关键词，页面按名称/描述/标签/分类实时过滤
3. 点击分类胶囊可平滑滚动到对应分组，滚动时分类会自动高亮
4. 点击任意卡片在新标签页打开对应资源

## 注意事项

- 搜索与分类导航仅在客户端挂载后生效，未挂载时展示与正式结构一致的骨架屏
- 点击分类导航的平滑滚动会检测系统「减少动态效果」偏好，开启时退化为瞬时跳转
- Prism 未注册的语言不会报错，将按纯文本渲染；新增语言需在 `prismLanguages.ts` 中追加注册
- 剪贴板与相对时间已收敛为单一实现，后续新增功能请直接引用对应工具模块，避免重复实现
