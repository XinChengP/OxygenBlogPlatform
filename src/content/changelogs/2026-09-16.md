## 功能概述

重构音乐模块的加载与播放逻辑：歌单加载改为「网易云优先、失败降级本地音乐」，清理掉冗余的 `PreloadManager` 类与两个自定义 Hook，并重做播放器进度条与空状态；同时修复 Live2D 歌词与 React 原生气泡争抢同一 DOM 节点导致歌词时隐时现的问题。

## 主要变更

### 歌单加载与降级策略

- **网易云优先**：`getProcessedAudioList()` 改为优先返回网易云歌单，正常加载时行为与原先一致
- **自动降级**：当网易云歌单为空时（Meting 接口请求失败、歌单配置未启用、被反爬规则拦截），自动回退到本地音乐列表，避免播放器出现「列表全空、无可播内容」的状态
- **本地列表提取**：新增 `getLocalProcessedList()` 私有方法，从配置中筛出 `source` 为 `local` 或未标注来源的歌曲并批量处理资源路径；配置文件本身加载失败时，`getConfig()` 会返回默认配置中的 10 首本地歌曲兜底
- **错误态文案**：播放器错误提示由「音乐播放器加载失败」改为「歌单加载失败」，副标题补充说明「在线与本地歌单均未读取成功」，明确这是两条来源都取不到才会出现的情况

### 代码清理

- **移除 `PreloadManager` 类**：删除 `musicPlayerPreloader.ts` 中约 158 行的 `PreloadManager` 类（提供 `requestIdleCallback` 空闲预加载的高层 API），与现有加载流程职责重叠；文件中的 `MusicPlayerPreloader` 类保留不变
- **移除冗余 Hook**：删除 `useMusicHistory.ts`（280 行）与 `useMusicPlayer.ts`（294 行）两个自定义 Hook，播放状态统一由现有逻辑维护，减少状态来源分散带来的不一致

### 播放器 UI 优化

- **空状态图标**：列表为空时复用封面占位处的音符图标，避免纯文字空状态显得突兀
- **进度条重构**：
  - 左右两侧常驻显示当前播放时间与总时长，不再需要悬停才能看到时长
  - 进度条本体与交互事件移到内层，使拖拽百分比与气泡定位以进度条真实宽度为基准，不受两侧时间文字宽度影响
  - 悬停气泡改为只显示鼠标位置对应的跳转预览时间，不再重复展示「当前时间 / 总时长」
  - 时间数字使用 `tabular-nums` 等宽显示，避免秒数跳动时文字宽度抖动
- **封面圆形裁切**：封面由圆角矩形改为正圆，既契合唱片隐喻，也避免方形图片旋转时四角周期性扫出造成视觉噪点
- **滚动条美化**：播放列表自定义 WebKit 滚动条，宽度、轨道与滑块颜色与站点视觉统一
- **卡片高度写法**：主播放器卡片的高度从内联 `style` 改回 Tailwind 的 `min-h-[360px]`，保持修长比例的同时让内容垂直居中

### Live2D 歌词渲染修复

- **根因**：原 `.message` 气泡由 React 组件渲染，其 `opacity`、`display` 与文本内容全部由 React state 决定，而歌词渲染器需要逐帧直接改写 DOM，两者互相覆盖：
  - React 侧内置 5 秒淡出逻辑，会把 `opacity` 置 0；歌词渲染器仅在「歌词行号变化」时重设 `opacity`，遇到长前奏、长间奏时行号不变，歌词被隐藏后再也回不来
  - 只要 React 重渲染 `.message`（播放/暂停、悬停提示、切歌提示都会触发），就会用 state 中的旧文本把歌词整个冲掉
- **修复方案**：改为自建专属气泡元素 `#live2d-lyrics-bubble`，歌词期间通过 `html[data-live2d-lyrics="on"]` 隐藏原生 `.message`，彻底避免两方争抢同一个 DOM 节点
- **异步适配**：Live2D 异步加载，`#landlord` 容器可能晚于歌词启动才出现，因此气泡元素创建失败后在 rAF 循环中按 200ms 节流重试，而非每帧查询 DOM

## 使用方式

### 验证降级逻辑

1. 正常状态下打开站点，播放器加载网易云歌单
2. 若需验证降级分支，可临时断开网易云歌单配置或让请求失败
3. 此时播放器会自动切换到本地音乐列表，仍有内容可播

## 注意事项

- 降级为**自动行为**，无需手动开关；网易云恢复可用后下次加载会自动回到歌单模式
- 本地音乐列表依赖配置文件中 `source` 为 `local` 的条目，新增本地歌曲时请正确标注来源
- Live2D 歌词气泡为独立 DOM 元素，**不再受 React 消息的 5 秒淡出逻辑影响**，长前奏、长间奏期间歌词会持续显示
- `MusicPlayerPreloader` 类本身未删除，仍被播放器引用；本次仅移除了其上层的高层封装 `PreloadManager`
- 删除的两个 Hook 已无引用，如有外部代码调用需同步清理
