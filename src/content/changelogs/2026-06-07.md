## 更新概述

本次更新聚焦代码质量提升，通过 AI 辅助扫描发现并清理了 9 处功能重复但实现不同的冗余代码，统一了技术方案；同时将 GitHub Actions 从静态导出模式的空实现重构为基于 simple-git 的完整后端逻辑。

## 主要更新

### 代码冗余清理与技术方案统一

- **资源路径工具去重**：`getAssetPath()` 复用 `getBasePath()` 的基础路径推断逻辑，消除两者间重复的 GitHub Pages 检测与环境变量读取代码
- **Markdown 解析统一**：`blogActions.ts` 移除内嵌的 frontmatter 解析器，统一复用 `frontMatterUtils.ts`；`frontMatterUtils.ts` 使用 `gray-matter` 库替代手写 YAML 解析，提升健壮性
- **暗黑模式滤镜统一**：`DarkModeImage` 与 `DarkModeContent` 组件统一使用 `DarkModeFilters` 实现，消除重复滤镜逻辑
- **代码块模板提取**：`safeMarked.ts` 将重复的代码块 HTML 模板提取为公共片段，减少模板冗余
- **音乐播放器逻辑优化**：`globalMusicPlayerManager` 提取公共的 `regenerateRandomOrder` 方法，消除重复随机排序实现
- **动态图片网格复用**：`ImageGrid` 组件复用 `ImageViewer` 组件，移除冗余的独立查看器逻辑
- **移除废弃 Hook**：删除未使用的 `useThemeOptimized.ts` 文件，减少维护负担

### GitHub Actions 后端重构

- **空实现替换**：将静态导出模式下仅返回"不支持"错误信息的空 `githubActions.ts` 实现，重构为基于 `simple-git` 的完整后端逻辑
- **Git 状态检查**：新增 `GitStatus` 接口与 `getGitStatus` 函数，支持检测仓库状态、未提交文件、本地领先/落后提交数等
- **推送功能实现**：新增 `pushToGitHub` 与 `buildAndPush` 函数，支持自动提交并推送更改到远程仓库
- **类型安全增强**：保留并完善 `GitPushResult` 接口，统一操作结果返回格式

### 编辑器与类型修复

- **Markdown 编辑器优化**：`MarkdownEditor.tsx` 进行细节调整，提升编辑体验
- **环境类型声明修复**：修正 `next-env.d.ts` 中的类型引用配置

## 使用方式

### 代码冗余检查

1. 在项目中使用 `/grill-me` 深度提问模式
2. 让 AI 从"同一功能多实现"、"Hook 重复封装"、"组件模板重复"等维度扫描代码库
3. 根据 AI 给出的清单逐项确认并清理

### GitHub 推送（后台管理）

1. 在本地开发环境进入 `/admin/github` 页面
2. 系统将自动检测 Git 仓库状态（未提交文件、本地领先提交数等）
3. 填写提交信息后点击推送，后端通过 `simple-git` 执行自动提交与推送

## 注意事项

- `githubActions.ts` 的重构仅在本地开发环境生效，静态导出模式下相关功能仍不可用（符合预期设计）
- `frontMatterUtils.ts` 引入 `gray-matter` 后，YAML 解析行为更加标准，极端格式的 frontmatter 可能需要适配
- 删除 `useThemeOptimized.ts` 后，若其他分支仍有引用需同步清理
