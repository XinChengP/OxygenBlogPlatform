## 更新概述

这一天同时完成了两项新功能与一轮后台安全加固：首页新增只在 `/` 生效的背景特效层，复用现有「镜境」背景图并保留原 CSS 流星；开发日志新增「连更不辍」「月度劳模」等跨篇成就和成就说明弹窗；后台集中修复博客/图库路径穿越、Git 命令注入、域名匹配误判、window.open 拦截策略等问题，并修正备份恢复、统计数量和确认框回车误操作。当天还清理了拼音转换器的旧构建产物、补充一条动态，并修正 README 与历史日志的元数据。

## 主要变更

### 首页背景特效

- **只挂首页**：在 `src/app/page.tsx` 挂载 `HomeBackgroundFX`，其它路由不会创建 canvas；没有控制面板，效果集固定
- **复用背景图**：不重新下载 `镜境.webp`，通过 `BackgroundLayer` 的 cover/contain 几何反算图片矩形，水线、涟漪、风之光丝和左侧光斑在任意宽高比下都贴住背景
- **竖屏适配**：可见宽度不足时自动关闭风之光丝和柔光光斑，只保留星空、云海、水面流光、镜湖微光、风迹、浮尘和涟漪
- **流星保留原样式**：首页继续使用原有 `<Meteors />` 的 20 个 CSS 流星，没有新增 canvas 流星；同时去掉 demo 阶段的背景视差、鼠标追随光晕和控制面板
- **交互**：每 5–9 秒自动生成一次水面涟漪；点击/轻触首页背景可作为彩蛋触发，但会忽略按钮、链接、输入框、Live2D 画布等交互元素
- **性能与降级**：`requestIdleCallback` 后动态加载引擎并淡入；`prefers-reduced-motion`、`saveData`、低端设备跳过或降级；触屏/低端机 DPR 1.5、30fps，桌面 DPR 2；窗口 resize 只调整星星数量，不重建已有粒子；页面隐藏或首页滚出视口时暂停，卸载时取消 rAF、断开 observer、移除监听
- **配置**：`enableHomeFX` 总开关、`homeFXIntensity` 整体强度、`homeFXImageSize` 背景图原始尺寸；更换背景图时需同步尺寸，否则锚点会偏

### 成就系统与说明弹窗

- **跨篇成就**：新增「连更不辍」（连续 7 天每天都有日志，授予连续段最后一天）和「月度劳模」（单月第 15 篇日志）
- **单篇成就扩展**：新增「一笔带过」（正文不足 18 行）、「除虫日」（当天所有提交都是 fix）、「面面俱到」（提交覆盖 4 种及以上类型）、「洋洋洒洒」（正文中文字数 2500 及以上）；「人声鼎沸」改为正文 100 行及以上
- **成就说明弹窗**：日志页右侧新增「查看成就说明」，按提交数量、篇幅长短、提交类型、跨篇统计分组展示全部成就及触发条件，并说明自定义荣誉；支持 Esc 和点击遮罩关闭，使用 `Z_INDEX` 层级令牌，未锁定 body 滚动以避免 sticky 统计栏失效
- **计算逻辑**：`calculateAchievements` 改为接收 `{ commits, contentLineCount, charCount }`；新增 `getAchievementDescriptions`、`getCommitPrefix`、`countPlainChars`；服务端读取日志时统计正文纯文本字数，排序后执行 `applyGlobalAchievements`
- **旧日志补充**：为 2026-07-12、2026-09-16 两篇日志补充自定义荣誉 frontmatter

### 安全修复与后台稳定性

- **博客路径穿越**：slug 增加字符白名单并拒绝 `..`，`path.resolve` 后再做目录边界校验；创建、读取、更新、删除、批量改分类、批量隐藏全部走统一路径解析；空标题生成的 slug 兜底为时间戳
- **图库路径穿越**：新增 `resolveGalleryPath` 统一处理 `public` 下的路径，拦截 `../` 与绝对路径；删除只允许图片文件；上传增加 10MB 上限和 Windows 非法文件名过滤；扫描越界路径直接拒绝
- **Git 命令注入**：提交历史、备份历史、提交信息、恢复哈希改用 `execFile` 参数数组；数量收敛到 1–100；恢复哈希增加格式校验；备份导出改为先写 tar 文件再解压，避免 shell 管道与 Windows 二进制损坏；推送失败只重试当前分支设置上游，不再循环强推 main/master/develop
- **window.open 与域名匹配**：`isAllowedDomain` 改为严格相等或以 `.域名` 结尾，避免 `evil-xinchengp.cn` 这类伪造域名被误判为本站；`protectWindow` 按无地址、协议、同源/白名单、用户手势分层放行，拦截 `javascript:`/`data:` 等危险协议和非用户主动触发的站外弹窗
- **确认框回车**：`AdminConfirm` 仅在焦点不在 input/textarea/select/contenteditable 时响应 Enter，避免在其它输入框按回车误执行删除等确认
- **备份恢复**：备份清单补齐后台 hooks、工具函数、类型和站点设置；`copyItem` 返回真实文件数；恢复时先把原内容改名为 `.restore-old`，失败自动回滚；保留 `.restore-password`，避免每次备份后恢复密码失效；密码错误信息统一为中文；新增 `isGitRepo` 状态供前端判断仓库是否初始化
- **统计与交互**：后台博客、动态、日志、分类数量去掉人为 +1；标签云移除无效的「选中筛选」逻辑，改为纯展示并限制入场错峰；`AdminModal` 增加 dialog 语义、标题关联和打开/关闭焦点管理；`useAdminBlogs.refresh` 改为重新从服务端读取列表，删除、隐藏或批量改分类后不再显示旧数据

### 清理、文档与内容

- **拼音工具产物清理**：删除 `public/tools` 下拼音转换器的旧 `.d.ts`、`.js`、`.map` 编译产物；删除根目录 `.backup/`、`check-env.js`、`debug.log`、`index.html`；`.gitignore` 增加 `.venv/`、`.build-backup/`、`.backup/`
- **开发环境 CSP**：`layout.tsx` 在开发环境使用 `developmentCSP`（额外放行 `unsafe-eval`），避免与 `next.config.ts` 下发的开发响应头取交集后裁掉 React 调试所需能力
- **新动态**：新增 `src/content/moments/000022.md`（2026-10-19 00:24，含图片）
- **文档修正**：README 更新最后更新日期、依赖列表、图床/安全/工具说明与构建命令说明；修正 10-11、10-14、10-15、10-17、10-18 日志的 type 字段和重复/不准确内容

## 注意事项

- 首页特效只在 `/` 生效；关闭总开关用 `enableHomeFX`，调整整体强度用 `homeFXIntensity`；更换背景图时要同步 `homeFXImageSize`
- 成就由日志 frontmatter 自动计算，跨篇成就随全部日志动态变化；自定义荣誉仍通过 `honors` 字段配置
- 后台路径、命令与外链策略收紧后，非法 slug、越界路径、非用户手势触发的站外 `window.open` 会被拒绝；备份恢复失败会自动回滚
- 静态导出仍必须使用 `npm run build:pages`，它会临时替换并恢复 Server Actions 文件
