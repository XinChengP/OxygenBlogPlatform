## 功能概述

本次更新集中优化了页脚展示与网站部署稳定性：为 Footer 增加飞鱼游动特效、完善多平台备案信息展示；将生产构建从 Turbopack 切换到 webpack，修复静态导出时偶发的 CSS/资源 404 问题；同时清理 ESLint 配置、关闭 OptimizedImage 默认 WebP，并新增魔 ICP 验证文件。

## 主要变更

### 关于页面样式微调

- **新增微博社交链接**：在左侧个人信息区的社交链接列表中新增微博入口，并添加对应的 `weibo.svg` 图标资源
- **文字大小与布局**：调整左侧个人信息区的文字层级与间距，社交链接改为两行展示，避免单行过长

### Footer 视觉与信息增强

- **飞鱼游动特效**：引入本地 `fish.js` 与 `jquery.min.js`，在页脚背景绘制小鱼群游动效果；通过条件判断在移动端默认隐藏，避免误触和性能消耗
- **运行时间文案**：将"已稳定运行"调整为"本站已存活"，并整合到版权信息行
- **备案信息完善**：
  - 保留"津ICP备2025041817号"工业和信息化部备案
  - 新增"萌ICP备20261099号"备案链接
  - 新增"魔ICP备2026849076号-1"备案链接与验证文件
- **布局重构**：Footer 改为相对定位深色背景，文字使用白色阴影保证在飞鱼特效上的可读性；备案信息、运行时间和版权信息分层展示

### 构建与部署优化

- **切换 webpack 构建**：`package.json` 中的 `build`、`build:pages`、`export` 命令统一添加 `--webpack` 参数，规避 Turbopack 在静态导出时偶发缺失 chunk 导致 CSS/资源 404 的问题
- **移除 Turbopack 别名配置**：`next.config.ts` 中删除 `turbopack.resolveAlias`，actions 的静态导出版本替换改由 `prepare-static-export.js` 脚本处理
- **GitHub Pages 适配**：新增 `public/.nojekyll` 空文件，避免 GitHub Pages 忽略以下划线开头的 Next.js 资源
- **CI 内存优化**：`.github/workflows/deploy.yml` 中增加 `NODE_OPTIONS=--max-old-space-size=8192`，降低大项目构建时的 OOM 风险
- **lint 脚本调整**：`package.json` 的 lint 命令改为 `eslint src`，与 `eslint.config.mjs` 的忽略配置保持一致

### OptimizedImage 默认行为调整

- **关闭默认 WebP**：将 `enableWebP` 默认值从 `true` 改为 `false`，避免 GitHub Pages 静态导出后请求不存在的 `.webp` 资源
- **路径适配**：修正组件注释和逻辑中的路径处理说明，确保关闭 WebP 时直接回退到原始图片格式

### 代码质量

- **清理 ESLint 禁用注释**：移除 `Footer.tsx`、`BlogMarkdownComponents.tsx`、`Analytics.tsx` 等多处冗余的 `eslint-disable` 注释
- **配置 TypeScript ESLint 插件**：在 `eslint.config.mjs` 中启用 TypeScript 相关规则，并新增 `admin-backup` 目录忽略

## 使用方式

### 查看 Footer 飞鱼与备案

1. 滚动到任意页面底部
2. 观察页脚背景中的小鱼群游动效果（移动端隐藏）
3. 查看备案信息行，点击各备案链接可跳转至对应备案查询页

## 注意事项

- 飞鱼特效依赖 jQuery，已本地托管到 `public/js/`，首次访问页脚时会按顺序加载 jQuery 与 fish.js
- 切换到 webpack 构建后，开发服务器（`npm run dev`）默认仍使用 Turbopack，仅在生产构建时强制 `--webpack`
- WebP 默认关闭后，如需在支持的环境中启用，需在调用 `OptimizedImage` 时显式传入 `enableWebP={true}` 并确保存在对应 `.webp` 资源
- 魔 ICP 验证文件 `public/.well-known/moicp-verification.html` 需要能被公开访问才能完成备案验证
