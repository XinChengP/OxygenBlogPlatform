## 功能概述

修复后台管理侧边栏在导航列表渲染时违反 React Hooks 规则的问题，将 `usePathname` 从 map 回调子组件提升至父组件统一调用，同时同步更新待办事项数据。

## 主要变更

### AdminSidebar Hook 违规修复

- **问题定位**：`NavItemComponent` 在 `.map()` 回调中创建，其内部调用了 `usePathname`，违反 React Hooks 必须在组件顶层调用的规则
- **修复方案**：移除子组件内的 `usePathname` 调用，改为父组件 `AdminSidebar` 统一获取路由路径，再通过 props 逐层传入导航项
- **效果**：消除了开发环境下的 React 规则警告，避免潜在生产环境异常

### 待办事项数据更新

- **英语六级**：调整截止日期
- **开学补考**：新增补考待办项

## 技术实现

| 文件路径 | 说明 |
|---------|------|
| `src/components/admin/AdminSidebar.tsx` | 重构路径传递逻辑，父组件统一调用 `usePathname` 并向下传递 |
| `src/content/todo.json` | 更新待办截止日期和新增补考项 |

## 注意事项

- React Hooks 规则要求：Hook 只能在函数组件顶层或自定义 Hook 中调用，禁止在循环、条件或嵌套函数内调用
- 本次修复未改变侧边栏的视觉表现和交互逻辑，仅调整了内部数据流
