## 功能概述

对全站进行一轮性能与视觉规范的双重治理：建立卡片阴影 CSS 令牌体系并统一卡片圆角、悬停交互；清理冗余动画与硬编码色值，改用语义令牌适配明暗主题；同时为归档页补上标签溢出时的「全部标签查看浮层」，解决标签过多遮挡封面的显示问题。

## 主要变更

### 卡片阴影令牌体系

- **新增阴影变量**：在 `globals.css` 中定义 `--card-shadow`（静态）与 `--card-shadow-hover`（悬停）两档令牌，并注册为 `shadow-card` / `shadow-card-hover` 工具类，明暗模式各有一套取值
- **双层阴影设计**：静态档第一层极淡近影描出边缘、第二层柔和远影拉开层次；悬停档加深远影，配合天依蓝边框反馈，阴影本身保持中性不染色
- **暗色适配**：暗色模式下阴影更黑更柔，加大远影扩散以在深色背景中"托得住"卡片
- **全站替换**：博客列表、画廊、工具页、友链、归档、动态等页面的卡片统一替换为阴影令牌，删除各自硬编码的 `shadow-md` / `shadow-lg` 等散落写法

### 卡片视觉规范统一

- **圆角统一**：全站卡片圆角统一为 `rounded-xl`，不再混用 `rounded-2xl` / `rounded-3xl`
- **悬停交互统一**：悬停位移统一为 `-3`（原先部分页面幅度 `-8` 过大），悬停边框统一使用 `primary/30` 主题色
- **移除多余毛玻璃**：非浮动卡片的 `backdrop-blur` 效果移除，减少模糊合成开销，长列表滚动更流畅（页面衬底的全屏背景图场景除外）
- **PageHeader 收敛**：移除未使用的渐变预设，统一为天依蓝主题

### 全站性能与主题清理

- **删除冗余动画**：清理 `globals.css` 中堆积的装饰性动画与过渡规则，减少样式计算与重绘
- **硬编码色值治理**：关于页、博客列表、留言板、设置页、工具页、导航栏、分页、页脚、Giscus 评论板等处的硬编码色值替换为语义令牌，暗色模式一致性明显提升
- **设置页精简**：设置页样式大幅精简（约 147 行改动），去除重复定义

### 归档页标签溢出浮层

- **浮层触发**：归档卡片标签数量超出单行容量时，末尾显示"+N"提示，点击弹出浮层查看全部标签
- **展示逻辑**：浮层列出卡片完整标签列表，支持点击标签筛选文章；点击外部区域自动关闭

## 使用方式

### 查看全部标签

1. 进入归档页（时光河流）
2. 找到标签较多的文章卡片，末尾出现"+N"提示
3. 点击提示弹出浮层，查看并点击全部标签进行筛选

## 注意事项

- `shadow-card` / `shadow-card-hover` 为注册后的 Tailwind 工具类，新卡片请直接使用，不要再写硬编码阴影
- 卡片统一规范：`rounded-xl` + `bg-card/95` + `border-border` + 阴影令牌 + 悬停位移 `-3`
- 悬停位移由 Framer Motion 驱动，阴影与边框过渡由 CSS 过渡驱动，两者职责分离，避免全局 CSS 过渡与动画库冲突
