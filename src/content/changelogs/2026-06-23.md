## 功能概述

本次更新围绕 Live2D 看板娘系统展开深度重构，新增 RSS 订阅能力并完善 CSP 安全策略白名单；同时修复了看板娘在客户端初次渲染时的水合闪现、重复加载与消息残留问题，并补充了若干内容资源。

## 主要变更

### Live2D 看板娘深度重构

- **实例管理抽离**：将 Live2D 实例与资源管理逻辑从组件中抽离至 `live2dInstanceManager` 与 `live2dResourceManager` 两个工具模块，统一管理脚本加载、模型注册与资源释放
- **独立动态加载器**：新增 `Live2DDynamicLoader` 组件，仅在客户端按需加载看板娘，避免在服务端预渲染时执行 Live2D 相关 API
- **优化 Hook 拆分**：原 `useLive2DOptimized` Hook 重新设计，按"控制 / 加载 / 消息"职责拆分，提升可读性与可测试性
- **CSP 策略更新**：在 `cspConfig.ts` 中放宽对 Live2D 资源域的访问限制，确保 CDN 资源能够正常加载
- **入口集中导出**：在 `src/utils/index.ts` 中统一导出新工具模块与 Hook，避免业务侧散落深路径引用

### Live2D 水合与重复加载修复

- **水合闪现修复**：`Live2DController` 与 `LuoTianyiLive2D` 组件在挂载前增加 `mounted` 状态判断，确保仅在客户端挂载完成后才渲染实际内容，避免服务端占位与客户端真实节点的切换闪烁
- **重复加载防护**：在 `live2dMessageManager` 中维护已注册监听器集合，避免页面切换或热更新时重复挂载相同事件回调
- **消息残留清理**：组件卸载时显式清空待展示消息队列与定时器，防止跳转到其他页面后旧消息在新页面继续弹出
- **博客图片补全**：同步更新 `Engineering-Drawing-Record` 文章图片引用，修复部分图床资源失效的问题

### RSS 订阅功能

- **新增 RSS 路由**：在 `src/app/rss.xml/route.ts` 中实现标准 RSS 2.0 响应，根据博客文章 frontmatter 自动生成频道与条目
- **内容范围覆盖**：RSS 输出包含文章标题、发布时间、分类、标签、摘要、原文链接，并提供全文或摘要可选
- **入口链接注入**：在根布局 `layout.tsx` 的 `<head>` 中自动添加 `<link rel="alternate" type="application/rss+xml">`，便于阅读器自动发现订阅源
- **robots 配置**：更新 `public/robots.txt`，新增 RSS 抓取允许规则，确保搜索引擎和阅读器可正常拉取

### CSP 安全策略完善

- **hitokoto 与 51la 放行**：在 `cspConfig.ts` 与 `securityHeaders.ts` 中添加一言 API 与 51la 统计接口到 `connect-src` 白名单，解决请求被浏览器拦截的问题
- **Cloudflare Web Analytics**：新增 Cloudflare Web Analytics 域名到 CSP 白名单，适配后续接入分析服务的需要
- **完整性校验脚本**：新增 `public/js/integrity-check.js`，用于检测关键脚本是否被篡改

### 音乐播放器优化

- **冗余参数清理**：移除 `useMusicPlayer` 中 `regenerateRandomOrder` 的多余调用参数，简化随机播放初始化逻辑
- **播放器可见性工具**：抽出 `musicPlayerVisibility.ts`，统一管理设置页中"播放器显示"开关的状态切换

## 使用方式

### 订阅 RSS

1. 在 RSS 阅读器中添加 `https://<你的域名>/rss.xml` 作为订阅源
2. 或在博客任意页面点击 head 中的 RSS 自动发现链接
3. 阅读器会按发布时间倒序拉取所有已发布文章

### 体验 Live2D 新加载流程

1. 首次访问首页，确认看板娘正常加载且无控制台水合警告
2. 在多个页面之间快速切换，确认看板娘不重复加载脚本
3. 切换主题、离开页面再返回，确认消息不会出现残留

## 注意事项

- Live2D 资源管理器需要浏览器支持 `AbortController` 与 `Promise`，已在 `package.json` 中明确目标浏览器版本
- RSS 路由依赖 `gray-matter` 解析 frontmatter，确保文章格式符合规范
- CSP 白名单新增域名后需同步更新 `next.config.ts` 中的 `Content-Security-Policy` 头，避免重复配置
- 完整性校验脚本默认不启用，如需开启可在 `layout.tsx` 中按需引入
