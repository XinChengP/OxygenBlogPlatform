## 功能概述

本次更新聚焦项目整体结构优化与核心交互组件重构，清理了布局层冗余组件和样式注入逻辑，改用动态导入降低首屏负载；同时对 Live2D 看板娘和音乐播放器进行了事件机制与资源管理的深度重构，提升运行效率和代码可维护性。

## 主要更新

### 项目结构与性能优化

- **类型引用修复**：修正 `next-env.d.ts` 中的类型引用路径，从开发环境临时目录切换到正确的 `types` 目录，确保类型系统在不同环境下稳定工作
- **布局组件精简**：删除冗余的 `ClientRouterWrapper` 和 `RootLayoutClient` 组件，将相关逻辑合并到根布局中，减少组件嵌套层级
- **过渡样式迁移**：将页面过渡动画样式从 `SmoothScrollProvider` 的 JavaScript 动态注入迁移到 `globals.css` 全局样式表中，避免客户端重复计算和注入开销
- **重型组件动态导入**：对非首屏关键的大型组件启用 `next/dynamic` 懒加载，有效降低初始 JavaScript bundle 体积，提升首屏加载速度
- **Footer 运行时优化**：将运行时间计算从 React 状态驱动改为 `ref` 直接操作 DOM，消除每秒更新导致的组件重渲染
- **背景层逻辑简化**：清理 `BackgroundLayer` 中不必要的 `useMemo` 依赖缓存，改用更直接的响应式计算方式
- **安全组件清理**：移除 `SecurityProvider` 中冗余的安全初始化代码和上报逻辑，保留核心功能的同时降低运行时负担

### Live2D 组件重构

- **客户端检测清理**：移除 `Live2DController` 中冗余的客户端挂载检测逻辑，将环境判断职责上移至调用方
- **状态存储优化**：`LuoTianyiLive2D` 组件移除不必要的 `state` 和 `ref`，改用单一 `ref` 存储页面开始时间戳，减少 React 调度开销
- **脚本加载去重**：优化 Live2D 脚本动态加载逻辑，增加资源注入去重检查，避免在路由切换或热更新时重复加载相同脚本
- **事件监听统一管理**：引入 `AbortController` 集中管理所有事件监听器（主题切换、页面可见性、消息系统等），组件卸载时一键取消全部订阅，杜绝内存泄漏
- **主题切换简化**：简化暗黑/亮色模式切换监听逻辑，移除不必要的强制重新渲染，依赖 CSS 变量自动响应主题变化
- **消息系统重构**：重构看板娘消息队列系统，支持通过 `AbortSignal` 取消待展示的消息事件绑定，提升交互响应性
- **工具函数清理**：删除项目中未使用的工具函数和组件内部重复代码，保持模块职责单一

### 音乐播放器事件重构

- **定时同步移除**：彻底移除旧版基于 `setInterval` 的播放状态定时同步逻辑，全面改用 APlayer 原生事件驱动机制（`play`、`pause`、`timeupdate`、`ended` 等）
- **事件监听器统一管理**：在 `useMusicPlayer` Hook 中集中注册播放器事件，并在组件卸载时完整清理所有监听器，避免闭包残留和内存泄漏
- **进度存储节流**：重构 `MusicPlayer` 的 `timeupdate` 处理逻辑，增加节流控制，降低 localStorage 写入频率，减少 I/O 开销
- **歌曲切换简化**：移除冗余的歌曲结束自动切换封装逻辑，直接监听 APlayer 的 `ended` 事件并触发下一首，减少中间层抽象
- **资源加载去重**：修复 APlayer 实例化时可能导致的资源重复加载问题，在脚本和样式注入前增加存在性检查

## 使用方式

### 验证动态导入效果

1. 打开浏览器开发者工具的 Network 面板
2. 刷新首页，观察初始加载的 JavaScript 文件体积
3. 切换到其他页面（如画廊、工具页），确认重型组件在首次访问时才加载对应 chunk

### 验证播放器事件监听

1. 播放任意歌曲，观察控制台无 `setInterval` 相关日志输出
2. 快进/暂停/切换歌曲，确认进度条和播放状态同步准确
3. 听完一首歌，验证自动切歌行为正常
4. 离开页面后返回，确认 localStorage 中的播放进度已正确保存

### 验证 Live2D 资源加载

1. 打开首页，确认看板娘正常加载并展示欢迎语
2. 切换暗黑/亮色主题，确认看板娘主题联动正常
3. 快速切换页面多次，在 Network 面板中确认 `live2d.min.js` 仅加载一次

## 注意事项

- 删除 `ClientRouterWrapper` 和 `RootLayoutClient` 后，若其他分支或自定义页面仍有引用需同步清理
- `SmoothScrollProvider` 移除样式注入后，页面过渡效果依赖全局 CSS，确保 `globals.css` 已正确引入
- Live2D 的 `AbortController` 需要较新的浏览器环境（Chrome 66+、Firefox 57+、Safari 12.1+），旧版浏览器会自动降级到手动移除事件监听
- 音乐播放器的事件监听重构后，如遇到播放状态不同步问题，请检查 APlayer 实例是否正确初始化
- 动态导入的组件在服务端渲染阶段不会加载，确保这些组件已标记 `'use client'` 或不含客户端专属 API
- 本次优化涉及多个核心组件，建议在本地充分测试后再部署到生产环境
