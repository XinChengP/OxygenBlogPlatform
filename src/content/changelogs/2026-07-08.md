## 功能概述

本次更新在 Howler 播放器之上引入 LRC 歌词解析与渲染能力，并补全独立展开按钮动画；调整"定位"和"歌词"按钮的布局细节；同时对 Live2D 消息管理器、滚动管理器等周边模块进行适配性调整。

## 主要变更

### 歌词解析与渲染

- **LRC 解析器**：`src/utils/lrcParser.ts` 新增标准 LRC 格式解析工具，支持时间标签（`[mm:ss.xx]`）、多时间戳、ID 标签（如 `[ti:]`、`[ar:]`、`[al:]`）以及纯文本歌词
- **渲染层**：`src/utils/live2dLyricsRenderer.ts` 实现歌词渲染逻辑，支持当前行高亮、相邻行降透明度、滚动跟随
- **Live2D 联动**：将歌词渲染接入 Live2D 气泡体系，歌曲播放时气泡内同步展示当前歌词
- **播放进度联动**：基于 `howlerPlayerManager` 的 `playprogress` 事件驱动歌词时间轴

### 播放器 UI 与交互

- **定位按钮优化**：在控制按钮行中的"定位"按钮增加禁用态样式，当播放列表为空时按钮置灰且不可点击
- **歌词按钮布局**："显示歌词"按钮与"定位"按钮采用一致的圆角与配色，激活态使用天依蓝高亮
- **控制按钮行间距**：微调控制按钮行内边距与图标尺寸，确保新增按钮后整体不溢出
- **独立展开按钮**：`public/music.gif` 作为独立展开按钮的图标，hover 时放大至 1.1 倍，无其他装饰

### 历史与滚动管理

- **`useMusicHistory.ts`**：订阅 `howlerPlayerManager` 的 `historyupdate` 事件，展示最近播放的歌曲
- **`scrollManager.ts`**：新增"定位当前歌曲"调用，滚动播放列表使当前歌曲进入可视区域
- **`useLive2DLoader.ts`**：歌词组件加载时延后到歌曲实际开始播放

### Live2D 消息体系适配

- **`live2dMessageManager.ts`**：新增"播放中""切歌"等上下文消息
- **与歌词系统协调**：歌词高亮行时不再触发"角色提示"类消息，避免信息过载

## 使用方式

### 体验歌词功能

1. 播放含 LRC 歌词的歌曲（可在 `public/content/music.json` 中配置 `lrc` 字段或 `lrcUrl`）
2. 观察 Live2D 气泡内同步滚动展示当前歌词
3. 切换至其他歌曲，歌词自动重新加载
4. 点击播放器控制行"显示歌词"按钮可切换气泡内歌词显隐

### 体验"定位"按钮

1. 滚动播放列表使当前歌曲不在可视区域
2. 点击控制按钮行中的"定位"按钮
3. 播放列表自动滚动将当前歌曲高亮显示
4. 当播放列表为空时，按钮置灰不可点击

### 体验独立展开按钮

1. 在关闭播放器 UI 后，仅留下独立展开按钮
2. 鼠标 hover 按钮，GIF 放大 1.1 倍
3. 点击按钮，播放器 UI 整体滑出

## 注意事项

- LRC 解析器对异常格式（如空时间戳）做容错处理，解析失败时静默退化为纯文本
- 歌词渲染依赖 `Howl.play()` 触发 `playprogress` 事件，若暂停状态下不会更新高亮行
- 独立展开按钮仅在播放器 UI 被右下角按钮关闭时显示，不影响正常播放
- 歌词按钮与定位按钮处于同一行时，窄屏下可能换行，请保证控制行最小宽度
- Live2D 气泡宽度有限，过长歌词会被截断并以省略号显示
