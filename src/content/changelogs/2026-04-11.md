### 2.4 日志成就标签系统

#### 功能概述
为开发日志增加趣味性的成就标签系统，通过统计日志的关联提交数量和日志行数，自动授予不同的成就称号。

#### 成就类型

| 成就名称 | 触发条件 | 颜色 |
|---------|---------|------|
| 略感疲惫 | 关联提交数量 >= 10 且 < 20 | #7366ff |
| 肝爆了 | 关联提交数量 >= 20 | #e566ff |
| 麻雀虽小五脏俱全 | 关联提交 = 1 且 日志行数 > 55 | #ff66a6 |
| 人声鼎沸 | 日志行数 > 250 | #ff9966 |

#### 特性说明
- 成就标签显示在类型标签的左侧
- 可以同时显示多个成就（按优先级排序）
- 成就仅用于展示，不参与任何统计功能
- 行数计算基于原始文件内容，不包括 frontmatter

#### 技术实现

| 文件路径 | 说明 |
|---------|------|
| `src/types/changelogTypes.ts` | 成就类型定义和计算函数 |
| `src/utils/changelogUtils.ts` | 日志解析时计算成就 |

### 2.5 内容展示优化

#### 自动换行功能
- **全面换行支持**: 为所有 Markdown 元素（标题、段落、列表、引用、链接、代码等）添加自动换行
- **超长文本处理**: 使用 `overflow-wrap-anywhere` 确保超长单词（如 URL）也能在任何位置换行
- **表格适配**: 表格容器添加横向滚动，单元格内容自动换行

#### 布局修复
- **严格七三分栏**: 使用固定宽度百分比（70%/30%）和 flex-shrink-0/flex-grow-0 确保布局不被破坏
- **粘性定位优化**: 右侧图表区域随页面滚动保持固定，使用 sticky 定位
- **响应式断点**: 移动端自动切换为单列布局，桌面端严格保持七三分

## 五、Bug 修复与优化

### 5.1 ByteString 编码错误修复

#### 问题描述
- **错误信息**: `Cannot convert argument to a ByteString because the character at index 14 has a value of 20809 which is greater than 255`
- **影响范围**: GitHub API 请求、Live2D 资源加载
- **根本原因**: HTTP 请求头中包含中文字符，导致编码错误

#### 修复方案
- **GitHub API**: 将所有 API 请求的 `message` 字段从中文改为英文
- **Live2D 资源管理器**: 移除 HTTP 请求头中的中文字符注释

#### 技术实现

| 文件路径 | 修改内容 |
|---------|---------|
| `src/services/githubApi.ts` | message 字段: `上传图片` → `Upload image` 等 |
| `src/utils/live2dResourceManager.ts` | 移除 `Cache-Control` 头的注释 |

### 5.2 代码清理

#### 清理内容
- 删除不再使用的规范文档和检查清单文件
- 移除 package.json 文件末尾多余的空行
- 移除图床设置和快捷键提示相关代码

#### 技术实现

| 文件路径 | 修改内容 |
|---------|---------|

## 六、使用说明

### 6.1 后台管理功能

1. **访问后台管理界面**: 本地开发环境访问 `/admin`
2. **仪表盘**: 查看项目统计数据和快捷操作
3. **日志管理**: 在侧边栏点击"更新日志"进行管理
4. **代码备份**: 在"代码备份"模块创建、查看、恢复备份

### 6.2 更新日志页面

1. **切换图表类型**: 点击标题旁的图表图标切换面积图/折线图
2. **切换时间维度**: 点击"月/季/年"按钮切换统计维度
3. **查看类型详情**: 点击环形图扇形或底部统计项查看详情
4. **悬停交互**: 鼠标悬停在图表元素上查看荧光效果

### 6.3 隐藏博客功能

1. **标记隐藏**: 在博客 frontmatter 中添加 `hidden: true`
2. **查看隐藏文章**: 在归档页面点击"显示隐藏文章"筛选器
3. **彩蛋消息**: 发现隐藏博客时看板娘自动显示惊喜消息

## 七、注意事项

1. **Node.js 版本**: 升级后需要 Node.js 24+，请运行 `npm install` 更新依赖
2. **Electron 离线包**: 离线安装包大小约 110MB，已从 Git 历史中移除
3. **图表库**: 图表使用 Recharts 库实现，完全兼容 GitHub Pages 静态部署
4. **静态生成**: 所有数据在构建时静态生成，无需服务端 API
5. **主题适配**: 图表配色使用 CSS 变量，自动适配亮色/暗色主题
6. **成就标签**: 成就仅用于展示，不参与任何统计功能
7. **代码备份**: 代码备份功能仅在本地开发环境可用
