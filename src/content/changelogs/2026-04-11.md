## 功能概述

全面优化更新日志页面，采用全新的七三分栏布局，左侧展示日志列表，右侧添加数据可视化图表，提升用户体验和数据展示效果。

### 主要变更

#### 页面布局重构
- **七三分栏**: 左侧日志内容占 70%，右侧统计图表占 30%
- **粘性定位**: 右侧图表区域随页面滚动保持固定
- **响应式设计**: 移动端自动切换为单列布局

#### 时间趋势折线图
- **双模式切换**: 支持面积图和折线图两种展示方式
- **时间维度切换**: 支持按月、季、年三种维度查看
- **季节统计**: 3-5月为春、6-8月为夏、9-11月为秋、12-2月为冬
- **天依蓝配色**: 使用主题色系的三层渐变填充
- **交互效果**: 数据点悬停发光、活跃点放大动画

#### 类型分布环形图
- **环形展示**: 直观展示各类型更新占比
- **颜色编码**: 新功能(绿)、修复(红)、重构(蓝)、文档(紫)、样式(橙)、其他(灰)
- **荧光效果**: 鼠标悬停时扇形向外突出并显示荧光发光
- **交互选中**: 点击扇形可保持选中状态
- **统计摘要**: 底部展示各类型数量和百分比

#### 布局优化
- **严格七三分栏**: 使用固定宽度百分比（70%/30%）和 flex-shrink-0/flex-grow-0 确保布局不被破坏
- **粘性定位优化**: 右侧图表区域随页面滚动保持固定，使用 sticky 定位
- **响应式断点**: 移动端自动切换为单列布局，桌面端严格保持七三分

#### 日志内容自动换行
- **全面换行支持**: 为所有 Markdown 元素（标题、段落、列表、引用、链接、代码等）添加自动换行
- **超长文本处理**: 使用 `overflow-wrap-anywhere` 确保超长单词（如 URL）也能在任何位置换行
- **表格适配**: 表格容器添加横向滚动，单元格内容自动换行

#### 统计逻辑优化
- **时间排序**: 所有时间维度统计均按时间升序排列（从早到晚）
- **季节跨年处理**: 12月、1月、2月同属于12月那一年的冬季（例如：2025年12月、2026年1月、2026年2月都属于2025年冬）
- **数据动态更新**: 图表数据随日志更新自动同步

### 技术实现

| 文件路径 | 说明 |
|---------|------|
| `src/components/changelogs/ClientChangelogsPage.tsx` | 更新日志页面主组件（七三分栏布局） |
| `src/components/changelogs/TimeStatsChart.tsx` | 时间趋势折线图组件 |
| `src/components/changelogs/TypeStatsChart.tsx` | 类型分布环形图组件 |
| `src/types/changelogTypes.ts` | 统计函数（getMonthStats/getQuarterStats/getYearStats） |
| `src/setting/WebSetting.ts` | 天依蓝主题色配置 |

### 图表特性

#### 时间趋势图
- 支持月/季/年三种统计维度
- 面积图使用三层渐变填充（天依蓝→青色→深蓝）
- 折线图使用双色渐变描边
- 数据点带白色边框，活跃时放大并发光
- X轴标签简化显示（2025-12、2026-春等）

#### 类型分布图
- 环形图内径65px、外径95px
- 扇形间距8px，带白色边框
- 悬停时扇形外突8px并显示荧光效果
- 底部两列布局展示类型统计
- 渐变背景卡片，悬停时上浮放大

### 使用方式

- **切换图表类型**: 点击标题旁的图表图标切换面积图/折线图
- **切换时间维度**: 点击"月/季/年"按钮切换统计维度
- **查看类型详情**: 点击环形图扇形或底部统计项查看详情
- **悬停交互**: 鼠标悬停在图表元素上查看荧光效果

### 注意事项

- 图表使用 Recharts 库实现，完全兼容 GitHub Pages 静态部署
- 所有数据在构建时静态生成，无需服务端 API
- 图表配色使用 CSS 变量，自动适配亮色/暗色主题
- 右侧图表区域使用 sticky 定位，滚动时保持可见

## Bug 修复与优化

### ByteString 编码错误修复

#### 问题描述
- **错误信息**: `Cannot convert argument to a ByteString because the character at index 14 has a value of 20809 which is greater than 255`
- **影响范围**: GitHub API 请求、Live2D 资源加载
- **根本原因**: HTTP 请求头中包含中文字符，导致编码错误

#### 修复方案
- **GitHub API**: 将所有 API 请求的 `message` 字段从中文改为英文
- **Live2D 资源管理器**: 移除 HTTP 请求头中的中文字符注释

#### 修改文件
| 文件路径 | 修改内容 |
|---------|---------|
| `src/services/githubApi.ts` | message 字段: `上传图片` → `Upload image` 等 |
| `src/utils/live2dResourceManager.ts` | 移除 `Cache-Control` 头的注释 |

### Electron 升级与修复

#### 问题描述
- **问题**: Node.js 24 与 Electron 33 不兼容
- **症状**: Electron 无法启动，报错 `Electron failed to install correctly`
- **原因**: Electron 33 主要为 Node.js 20 设计

#### 解决方案
- **版本升级**: Electron 33 → Electron 34
- **离线安装**: 使用国内镜像下载 Electron 离线包
- **启动脚本**: 修复 `start-dev.bat` 直接运行 `electron.exe`

#### 修改文件
| 文件路径 | 修改内容 |
|---------|---------|
| `package.json` | Electron 版本升级到 34.0.0 |
| `start-dev.bat` | 改进检查逻辑，直接运行 `electron.exe` |
| `next.config.ts` | 添加 `allowedDevOrigins` 配置 |

#### 注意事项
- Electron 34 支持 Node.js 24
- 离线安装包大小约 110MB，已从 Git 历史中移除
- `start-dev.bat` 现在直接运行 `node_modules\electron\electron.exe`

## 隐藏博客与本地备份功能

### 功能概述

本次更新包含三项功能开发：隐藏博客文章系统、Live2D 看板娘彩蛋消息、本地代码备份管理功能。

### 主要变更

#### 隐藏博客文章功能
- **隐藏标记**: 支持将博客文章标记为隐藏
- **隐藏筛选**: 归档页面新增"显示隐藏文章"筛选选项
- **访问控制**: 隐藏文章在公开列表中不显示
- **URL 访问**: 知道文章链接的用户仍可访问隐藏文章

#### 看板娘彩蛋消息功能
- **发现提示**: 用户发现隐藏博客时显示惊喜消息
- **特殊提示**: 展示隐藏博客的特殊提示信息
- **消息模板**: 支持 `{text}` 占位符替换
- **优先级机制**: 彩蛋消息使用高优先级确保显示
- **多种场景**: 区分"发现隐藏"和"特殊备注"两种消息类型

#### 本地代码备份管理功能
- **备份创建**: 支持创建当前代码的备份快照
- **备份列表**: 查看所有本地备份记录
- **备份恢复**: 支持从备份恢复代码状态
- **备份删除**: 清理不需要的备份释放空间

### 技术实现

| 文件路径 | 说明 |
|---------|------|
| `src/components/archive/ArchiveClient.tsx` | 归档页面组件（隐藏筛选） |
| `src/setting/live2dMessages.ts` | Live2D 消息配置（彩蛋消息） |
| `src/components/admin/AdminCodeBackup.tsx` | 代码备份管理组件 |
| `src/actions/backupActions.ts` | 备份操作 Server Actions |
| `src/hooks/useCodeBackup.ts` | 代码备份 Hook |

### 使用方式

- **隐藏博客**: 在博客 frontmatter 中添加 `hidden: true` 标记
- **查看隐藏文章**: 在归档页面点击"显示隐藏文章"筛选器
- **彩蛋消息**: 发现隐藏博客时看板娘自动显示惊喜消息
- **代码备份**: 在后台管理界面的"代码备份"模块进行操作

### 功能特性

- **隐藏博客**: 灵活的隐藏/显示控制，不影响正常访问
- **彩蛋消息**: 增强互动体验，发现隐藏内容时给予正向反馈
- **代码备份**: 本地开发环境的代码安全保障

### 注意事项

- 隐藏博客功能仅影响列表显示，不影响文章访问
- 彩蛋消息使用 `HiddenTagEasterEggMessages` 配置
- 代码备份功能仅在本地开发环境可用
