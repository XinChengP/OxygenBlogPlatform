## 功能概述

本次更新带来了全面的后台管理功能增强和系统升级。项目成功升级至 Node.js 24，新增本地代码备份管理、更新日志可视化统计、隐藏博客文章等实用功能，同时对 Live2D 看板娘进行了彩蛋消息增强。后台管理界面新增了仪表盘和日志管理入口，整体开发体验得到显著提升。本次更新共完成 **23 次提交**。

### 主要变更

#### 本地代码备份管理
- **创建备份**: 支持创建代码快照，采用 zip 压缩格式存储
- **备份历史**: 查看所有备份记录，包含创建时间和文件大小
- **恢复版本**: 支持恢复到指定备份版本，操作前需密码验证
- **安全保障**: 恢复操作需要密码验证，防止误操作导致数据丢失

#### 后台仪表盘
- **统计数据**: 集中展示博客数量、动态数量、日志数量、待办进度
- **卡片布局**: 采用卡片式布局，配合图标和数字展示
- **快捷操作**: 提供常用功能页面的快速入口

#### 更新日志管理
- **后台入口**: 侧边栏新增更新日志管理入口
- **Markdown编辑器**: 支持实时预览的 Markdown 编辑器
- **增删改查**: 完整的日志创建、编辑、删除功能

#### 数据可视化图表
- **时间趋势图**: 展示不同类型日志的数量变化趋势
- **类型分布图**: 环形图展示各类型的占比情况
- **维度切换**: 支持按月、季、年三个维度切换查看
- **主题适配**: 使用 CSS 变量自动适配亮色/暗色主题

#### 成就标签系统
- **自动计算**: 根据提交数量和日志行数自动计算成就
- **成就类型**: 略感疲惫、肝爆了、麻雀虽小五脏俱全、人声鼎沸
- **展示位置**: 成就标签显示在类型标签左侧

#### 隐藏博客文章
- **隐藏标记**: 在 frontmatter 中添加 `hidden: true` 标记隐藏
- **筛选查看**: 归档页面支持显示/隐藏隐藏文章
- **彩蛋消息**: 发现隐藏博客时看板娘显示惊喜消息

#### 文章置顶功能
- **置顶标记**: 支持设置 `pinned: true` 置顶文章
- **置顶时间**: 支持 `pinnedAt` 字段记录置顶时间
- **优先展示**: 置顶文章优先展示在列表最前方

#### Live2D 彩蛋消息
- **画廊页面**: 添加画廊页面的消息配置
- **动态页面**: 添加个人动态页面的消息联动
- **日志页面**: 添加更新日志页面的消息展示

#### Node.js 24 升级
- **依赖更新**: 更新相关依赖包和类型定义到 v24
- **CI配置**: GitHub Actions 强制使用 Node.js 24
- **性能提升**: 获得最新的语言特性和安全补丁

### 使用方式

- **后台管理**: 本地开发环境访问 `/admin` 进入后台管理界面
- **更新日志图表**: 点击标题旁图表图标切换面积图/折线图，点击"月/季/年"切换维度
- **隐藏博客**: 在博客 frontmatter 中添加 `hidden: true`，在归档页面可筛选查看
- **置顶文章**: 在博客 frontmatter 中添加 `pinned: true` 和 `pinnedAt` 时间

### 注意事项

- 升级后需要 Node.js 24+，请运行 `npm install` 更新依赖
- 图表使用 Recharts 库实现，完全兼容 GitHub Pages 静态部署
- 所有数据在构建时静态生成，无需服务端 API
- 代码备份功能仅在本地开发环境可用
- 成就标签仅用于展示，不参与任何统计功能
