## 功能概述

添加完整的待办事项管理功能，包括前台展示和后台管理。重构多个页面统一使用新的 PageHeader 组件，更新项目文档和技能说明。

### 主要变更

#### 待办事项功能
- 新增待办事项管理功能模块
- 支持优先级设置（高/中/低）
- 支持完成状态切换
- 支持完成进度统计
- 在动态页面侧边栏展示
- 支持本地开发环境后台管理

#### 统一页面标题组件
- 重构 `PageHeader` 组件，统一接口设计
- 重构所有页面使用新的 PageHeader 组件
- 统一页面标题样式和布局

#### 文档更新
- 更新项目文档和开发规范
- 更新技能说明文档
- 完善待办事项功能文档

#### 样式调整
- 调整友链组件悬停变色样式
- 优化相关链接组件交互效果

### 技术实现

| 文件路径 | 说明 |
|---------|------|
| `src/components/ui/PageHeader.tsx` | 统一的页面标题组件 |
| `.trae/rules/project_rules.md` | 更新项目开发规范 |
| `.trae/skills/todo-manage/SKILL.md` | 待办管理技能说明 |
| `README.md` | 更新项目说明文档 |
| 多个页面文件 | 重构使用新的 PageHeader |

### 使用方式

- **前台展示**: 访问动态页面，在侧边栏查看待办事项
- **后台管理**: 本地开发环境访问 `/admin/todo` 进行管理
- **页面标题**: 所有页面自动使用统一的 PageHeader 组件

### 功能特性

- **优先级标记**: 不同优先级使用不同颜色标记
- **完成统计**: 显示完成进度和统计信息
- **静态部署**: 数据存储在 JSON 文件，支持静态部署
- **响应式设计**: 适配移动端和桌面端

### 注意事项

- 后台管理仅在本地开发环境可用
- 修改待办事项后需要重新构建部署
- 待办数据存储在 `src/content/todo.json`
