## 更新概述

评论系统上线后的集中收尾：修复表情面板打不开的问题（CSP 漏放行表情数据源），完成 giscus 历史评论的正式导入并修正回复关系，配置博主身份识别与固定头像。

## 主要变更

### 表情面板修复

- **问题**：线上表情按钮点击无反应——按钮是个空壳，表情面板从未初始化
- **根因**：表情数据源 `owo.imaegoo.com` 未登记进 CSP 白名单，表情 JSON 被静默拦截（curl 直连正常、页面内 fetch 0ms 失败即 CSP 拦截的特征），初始化链路中断
- **修复**：白名单补登记该来源，表情面板恢复正常（颜文字 / Emoji / Bilibili 三组）

### 历史评论导入与回复关系修正

- 30 条 giscus 历史评论（19 评 + 13 回复，剔除已删文章的测试评论）正式导入线上数据库
- **导入后修正**：Workers 版 Twikoo 的保存逻辑会用新 uuid 覆盖评论 `_id`，导致回复的 `pid/rid` 指向失效、13 条回复全部显示为顶层——导入后按「路径 + 时间」对齐重写了全部回复的指向，断链归零，留言板与各文章页回复树恢复正常嵌套
- 两组因 giscus 时代新旧路径各建一个讨论而产生的重复评论已识别，待人工择删

### 博主身份与头像

- **博主识别**：配置 `BLOGGER_EMAIL`，发评论填该邮箱即显示博主徽标（用博主邮箱发言需先登录管理面板，防冒充）
- **固定头像**：为后端新增 `BLOGGER_AVATAR` 配置键——博主评论一律使用指定头像（当前为 GitHub 头像直链），不跟随 QQ 头像；历史评论的 GitHub 头像与其保持一致
- **配置修正**：`GRAVATAR_CDN` 曾误填单张图片 URL（该键应为 CDN 域名），会导致访客头像全部失效，已清空恢复默认头像源

## 注意事项

- `BLOGGER_AVATAR` 是对 Workers 后端的本地补丁，升级上游适配器时需重打（`cloudflare/twikoo/src/index.js` 内有注释标记）
