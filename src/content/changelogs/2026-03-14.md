## 功能概述

添加Electron支持，实现桌面应用开发预览能力，提供原生窗口管理、菜单栏和开发工具集成。

### 主要变更

#### 基础架构
- 创建 Electron 主进程 (`electron/main.js`)
- 创建预加载脚本 (`electron/preload.js`)
- 实现与 Next.js 开发服务器的集成

#### 窗口管理
- 实现基本窗口管理功能
- 支持窗口大小调整和状态记忆
- 添加窗口关闭确认提示

#### 菜单栏
- 实现原生菜单栏支持
- 添加文件、编辑、视图等常用菜单
- 支持页面导航快捷操作

#### 开发体验
- 添加开发者工具快捷键支持
- 支持热重载开发模式
- 添加页面导航快捷键

### 技术实现

| 文件路径 | 说明 |
|---------|------|
| `electron/main.js` | Electron主进程 |
| `electron/preload.js` | 预加载脚本 |
| `package.json` | 添加Electron依赖和脚本 |
| `package-lock.json` | 依赖锁定文件更新 |

### 使用方式

```bash
# 安装依赖
npm install

# 启动Next.js开发服务器
npm run dev

# 在另一个终端启动Electron
npm run electron
```

### 注意事项

- Electron模式仅用于本地开发预览
- 需要先启动 Next.js 开发服务器才能运行Electron
- Electron打包生产版本需要额外配置
