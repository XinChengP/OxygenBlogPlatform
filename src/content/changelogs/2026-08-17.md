## 功能概述

对宠物模拟器进行 UI 全面优化，使用 CSS 变量替换硬编码颜色、实现移动端选项卡切换、优化视觉层次；同时新增宠物数据并调整数据组织结构，清理冗余依赖。

## 主要变更

### 宠物模拟器 UI 优化

- **CSS 变量化**：使用 `--color-primary`、`--color-card`、`--color-border` 等 CSS 变量替换硬编码颜色，支持主题切换
- **移动端适配**：实现移动端选项卡切换（阵容/宠物/禁用），桌面端保持侧边栏布局
- **视觉层次优化**：优化筛选/搜索/账号区域的视觉层次和间距
- **模态框统一**：统一模态框样式，使用 `bg-[var(--color-card)]` 和 `border-[var(--color-border)]`
- **宠物卡片增强**：新增魔法值徽章展示和 hover 效果
- **Bug 修复**：修复隐藏魔法宠物时三元表达式缺少 `: []` 分支的问题

### 宠物数据更新

- **新增宠物**：新增两只 3 魔法宠物——伊里斯和伊莉斯
- **数据重组**：将部分 1 魔法经典宠物移入专属"梦境专场"分类
- **天赋扩展**：新增折射、童话书页、溺海秘法等天赋配置
- **专属配置**：补充新宠物的专属组别、皮肤和天赋数据

### 依赖清理

- **移除冗余依赖**：清理 `package.json` 中不再使用的依赖包
- **资源更新**：更新 `package-lock.json` 和部分资源引用

## 使用方式

### 移动端体验

1. 在移动设备上打开宠物模拟器
2. 页面底部出现选项卡切换栏（阵容/宠物/禁用）
3. 点击选项卡切换不同视图，桌面端仍为侧边栏布局

### 宠物卡片

1. 在宠物列表中查看宠物卡片
2. 卡片上显示魔法值徽章，直观展示宠物魔法等级
3. 鼠标悬停卡片时显示 hover 效果

## 注意事项

- CSS 变量化后，主题切换将自动影响宠物模拟器样式
- 移动端选项卡与桌面端侧边栏为自适应切换，无需手动设置
- 清理依赖后需重新运行 `npm install` 确保依赖正确
