## 更新概述

这一天的主线是"把常驻开销拆掉、把重排问题根治"。画廊页从 CSS 多列瀑布流改为预计算的横向行式布局，滚动加载不再整页抖动；图床缩略图改为内容寻址命名，彻底解决图库重排后"缩略图与灯箱原图对不上"的错位；博客正文与全站背景图接入构建期生成的多档 WebP 变体，手机端不用再下载十几 MB 的原图。同时把常驻动画改成定时器状态机与纯 CSS，Live2D、鱼群特效、打字机、安全监控全部改为按需加载或降频，开发日志与个人动态正文改为构建期预渲染，浏览器不再下载整套 Markdown 解析栈。

## 主要变更

### 画廊：从瀑布流到横向行式布局

- **行式布局算法**：新增 `src/utils/galleryLayout.ts`，按清单里的宽高把图片预先切成一条条固定高度的横向行。行与行相互独立，追加图片只在末尾新增行，已经渲染在屏幕上的卡片不会再挪位
- **极端比例钳制**：用于布局的宽高比限制在 `0.45 ~ 4` 之间，避免 1200×15960 这类长图被算成 20px 宽的细条；完整长图仍交给灯箱查看
- **比例穿插**：横屏 / 竖屏 / 方图按 `6:6:1` 权重用平滑加权轮询（SWRR）穿插，避免出现长串同比例图片；表情包固定排在最后，用更矮的方形密排行承载
- **入场动画拆分**：卡片入场动画由"每张一个动画实例"改为"每行一次"，且只给前若干行做错峰，几百个动画实例不再同时占用主线程
- **行级离屏渲染**：行容器加 `content-visibility: auto`，视口外的行由浏览器跳过绘制与样式计算，等效于轻量虚拟化
- **分批渲染**：`IntersectionObserver` 在接近底部时追加下一批行，同时保留手动"加载更多"按钮，供不支持观察器的环境使用
- **画框固定尺寸**：`ImageCard` 新增 `displayWidth` / `displayHeight` 入参，格子宽度与画框高度由行布局直接给出，图片未加载前就占好位置；同时移除展签式图注，改为悬停显示标题与编号
- **加载状态兜底**：给原生 `img` 直接挂 `load` / `error`，挂载时若 `complete` 立即结算，解决服务端直出图片在水合前就加载完、React `onLoad` 不触发而一直停在骨架屏的问题

### 图床缩略图与灯箱

- **内容寻址命名**：`build-manifest.mjs` 用源图 `sha1` 前 8 位命名 `thumbs` / `large` 变体文件，清单新增 `hash` 字段。图库管理器做"编号规整"重排后，同一序号路径换成另一张图时必然生成新 URL，CDN 固定路径缓存不再返回旧缩略图
- **增量策略简化**：文件名本身带内容哈希，文件存在即代表内容一致，不再比对 `mtime` 跳过编码
- **孤儿清理**：按清单实际引用删除不再被引用的变体文件，避免换图后旧缩略图滞留
- **高清预览尺寸**：清单新增 `large` 字段（1280 / 1920 WebP），灯箱优先加载中间尺寸，缺失时回退原图，避免直接拉十几 MB 原图
- **清单超时放宽**：R2 清单请求超时从 10 秒放宽到 25 秒。清单一共约 160KB，网络较差时 10 秒会超时并退化到没有缩略图、没有宽高的 GitHub Trees 快照，导致静态首屏卡片全丢缩略图；25 秒仍低于 Next 静态生成单页 60 秒的失败阈值
- **图床预连接**：`layout.tsx` 为图片域名增加 `preconnect` / `dns-prefetch`，首屏缩略图少一次 TLS 握手

### 原图下载

- **下载入口**：灯箱右侧工具栏新增下载按钮，`href` 始终指向原图 `src`，不受灯箱预览使用 `large` 的影响
- **体积提示**：按钮悬浮提示会显示原图体积（大于 1MB 显示 `x.xMB`，否则显示取整的 KB），数据来自清单新增的 `size` 字段
- **类型补充**：`PreviewImage` 增加 `size?: number`，单位字节

### 响应式图片体系

- **正文图片变体**：新增 `scripts/generate-responsive-images.js`，构建前扫描博客 Markdown 的图片语法、原生 `<img>` 与 frontmatter 的 `coverImage`，用 `sharp` 生成 640 / 1280 / 1920 三档 WebP（质量 78），并输出清单 `src/data/blogImageManifest.json`
- **产物与缓存**：变体写入 `public/_responsive/`（已加入 `.gitignore`），源图未变化时用 `node_modules/.cache` 缓存跳过，不重复编码
- **小图处理**：宽度不足 641 的图片不生成变体，但仍记录宽高，供 `<img width/height>` 使用，避免布局跳动
- **背景图 srcset**：新增 `src/data/backgroundImageManifest.json`，`layout.tsx` 在 head 中以 `imageSrcSet` + `imageSizes="100vw"` + `fetchPriority="high"` 预加载，浏览器按视口与 DPR 选档，手机不再下载 460KB 原图
- **首载包隔离**：`src/utils/responsiveImage.ts` 不再导入博客图片清单（59KB），避免它跟着全局 `BackgroundLayer` 进入全站首载包
- **构建接入**：`build-pages.js` 在 `next build` 之前先执行变体生成，失败即终止构建，不产出缺清单的站点

### 全站性能治理

- **去掉常驻动画库**：打字机组件改为 `setTimeout` 状态机（打字 60ms/字、删除 30ms/字、整句停留 1.5s），标签页隐藏时暂停，`prefers-reduced-motion` 时直接显示静态文本。首页不再引入 framer-motion，首载少一个约 41KB(gzip) 的 chunk
- **Live2D 门控**：`Live2DDynamicLoader` 在首页、404、后台不加载；触屏设备、省流模式、减少动态效果时跳过下载；其余路由在 `requestIdleCallback` 空闲时段才加载模型代码。一旦加载过就保持挂载，路由切回首页只隐藏，避免反复初始化
- **鱼群特效**：`fish.js` 抽出 `teardown()` 统一取消 rAF、解绑 resize / 鼠标 / `visibilitychange` 监听、断开 `IntersectionObserver`；新增页面可见性暂停与恢复；缓存容器颜色避免每帧 `getComputedStyle` 触发强制样式计算；移动端、省流模式、减少动态、宽度小于 768 时直接不加载脚本（此前只是 CSS 隐藏，脚本照样创建画布）
- **运行时间**：页脚从 `requestAnimationFrame` 每帧检查改为 `setInterval` 每秒更新，标签页隐藏时跳过，后台路由不启动计时
- **安全监控降频**：生产环境关闭 DOM 与脚本的 `MutationObserver`（React 水合与列表渲染时会产生大量记录与递归 `querySelectorAll`），只保留低成本的 iframe 逃逸检查与网络请求检查；检查间隔从 15 秒放宽到 60 秒；完整性检测脚本默认不加载，需要时显式开启
- **正文预渲染**：新增 `MomentMarkdown` / `ChangelogMarkdown` 两个服务端渲染器，动态页与日志页不再向浏览器下发 `react-markdown` + `remark` / `rehype` 整套解析栈（约 195KB gzip）
- **日志按需展开**：日志正文由 `scripts/generate-changelog-html.tsx` 在构建期渲染成 `public/_changelog-content/<id>.html`，初始页面不下发正文，用户第一次展开某条日志时再按需请求对应片段
- **延迟挂载**：新增 `DeferredMount` 组件，图表、地图等大型资源进入视口或空闲时再挂载
- **骨架屏移除**：删除 archive、blogs、blogs/[slug]、changelogs、gallery、moments 各路由的 `loading.tsx`，静态导出路由切换不再先闪骨架再闪真实内容

### 构建流程与文档

- **环境变量注入**：`build-pages.js` 在启动 `next build` 时显式注入 `NODE_ENV`、`STATIC_EXPORT`、`NEXT_PRIVATE_STATIC_EXPORT`，不再依赖 `.env.production` 的加载时机，防止静态导出标记偶尔没生效
- **构建前置任务**：`predev` / `prebuild` 增加 `generate:changelog-html`，与响应式图片生成一起在构建前完成
- **对接文档**：新增 `docs/gallery-loading-handoff.md`，记录图床资产构建、清单结构、变体命名与部署约定（792 张图片已上线，Secrets 尚待配置）

## 使用方式

### 下载原图

1. 打开画廊页，点击任意图片进入灯箱
2. 右上角工具栏点击下载图标，浏览器直接下载原图
3. 鼠标悬停在下载图标上可看到原图体积提示

### 本地构建与预览

1. 首次拉取代码或清理过 `public/_responsive/` 后，先执行 `npm run generate:responsive`
2. 需要日志正文片段时执行 `npm run generate:changelog-html`
3. 使用 `npm run build:pages` 进行静态导出构建（会自动完成上面两步）

## 注意事项

- 响应式变体与日志正文片段都是构建产物，`public/_responsive/`、`public/_changelog-content/` 不纳入版本管理，部署时必须随 `out/` 一起上传
- 图床清单的 `thumbs` / `large` 文件名带内容哈希，换图或重排后旧变体由孤儿清理删除；若 CDN 仍显示旧图，先确认部署是否覆盖了新的清单
- 图库刷新会等待清单最多 25 秒，超时后回退 GitHub Trees 快照，此时卡片没有缩略图、宽高与 `large`，属于预期降级行为
- 画廊布局不再使用 CSS 多列瀑布流，卡片尺寸由行布局计算得出，修改列宽或间距时需要同步调整 `galleryLayout` 的配置
- Live2D 在首页、404 与后台不加载，从其它页面切回首页只是隐藏模型；触屏设备与省电模式默认不加载模型与鱼群特效
- 生产环境已关闭 DOM / 脚本篡改监控，如需恢复需在 `SecurityProvider` 中显式开启对应开关
- 静态导出仍必须使用 `npm run build:pages`，它会临时替换并恢复 Server Actions 文件
