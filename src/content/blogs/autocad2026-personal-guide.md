## 一、基础操作

### 1.1 常用命令

#### 基础绘图命令

| 命令 | 全称 | 功能 |
|------|------|------|
| L | LINE | 绘制直线 |
| C | CIRCLE | 绘制圆 |
| REC | RECTANGLE | 绘制矩形 |
| PL | PLINE | 绘制多段线 |
| A | ARC | 绘制圆弧 |

#### 修改命令

| 命令 | 全称 | 功能 |
|------|------|------|
| CO | COPY | 复制对象 |
| M | MOVE | 移动对象 |
| RO | ROTATE | 旋转对象 |
| SC | SCALE | 缩放对象 |
| TR | TRIM | 修剪对象 |

### 1.2 快捷键

熟练使用快捷键可以大大提高绘图效率：

```
Ctrl + S    保存
Ctrl + Z    撤销
Ctrl + Y    重做
Ctrl + C    复制
Ctrl + V    粘贴
```

## 二、图层管理

### 2.1 图层的作用

图层是 Auto CAD 中非常重要的概念，它可以帮助我们：

- 区分不同类型的图形元素
- 方便控制图形的显示和打印
- 实现图形的分类管理

### 2.2 图层设置

创建图层时需要设置以下属性：

- 图层名称
- 图层颜色
- 图层线型
- 图层线宽
- 图层打印样式

## 三、标注与文字

### 3.1 尺寸标注

Auto CAD 提供了多种尺寸标注类型：

- 线性标注（DLI）
- 对齐标注（DAL）
- 角度标注（DAN）
- 半径标注（DRA）
- 直径标注（DDI）

### 3.2 文字样式

在添加文字之前，需要先设置文字样式：

- 字体选择
- 高度设置
- 宽度比例
- 倾斜角度

## 四、块与属性

### 4.1 块的创建

块是由多个对象组成的组合对象，可以重复使用：

- 定义块（B）
- 插入块（I）
- 写块（W）

### 4.2 属性块

属性块是可以包含可变信息的特殊块：

- 定义属性
- 编辑属性
- 提取属性数据

## 五、常见问题与解决方案

### 5.1 绘图问题

- **直线画不直**：检查是否开启了对象捕捉
- **标注显示异常**：检查标注样式设置
- **文件打开缓慢**：可能是图纸元素过多

### 5.2 技巧分享

- 合理使用栅格和捕捉
- 善于利用查询功能
- 定期清理图纸垃圾数据

## 六、总结

学习 Auto CAD 需要大量的练习，熟练掌握基础命令和操作技巧是非常重要的。本文会随着学习的深入不断更新和完善，希望能够帮助到有同样学习需求的你。
